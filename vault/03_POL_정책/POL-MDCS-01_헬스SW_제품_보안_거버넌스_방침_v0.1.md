# 헬스SW 제품 보안 거버넌스 방침 (POL-MDCS-01)

> 상위 기준: [[표준프로세스_구성원칙]] · 문서체계: [[01_문서체계]] · 적용요건: [[적용요건]]
> 영역: **MDCS** · Layer: **L2_engineering** · Integration mode: **interface_only**

## 1. 목적
본 방침은 당사가 제조·공급하는 **헬스SW(HEALTH SOFTWARE)** 제품에 대해, IEC 81001-5-1:2021 이 요구하는 **제품 수명주기 보안 활동**을 확립·운영·지속개선하기 위한 거버넌스 방향과 원칙을 정의한다. 모든 헬스SW 제품에는 **안전 등급 구분 없이 균일하게** 본 방침이 적용된다.

## 2. 적용 범위
본 방침은 보안 수명주기가 적용되는 것으로 식별된 **헬스SW 제품 또는 제품 일부**, 그 개발·유지보수·지원에 관여하는 모든 조직 역할, 그리고 제조자 전용·특정 목적으로 개발되며 보안에 영향을 줄 수 있는 **제3자 SOFTWARE ITEM** 에 적용된다. 적용 대상의 식별·문서화는 [[PRO-MDCS-01-01_보안_거버넌스_및_일반요건_관리_절차_v0.1]] 에 따른다.

## 3. 정책 원칙
1. **QMS 기반 운영** — 모든 보안 수명주기 활동은 문서화·확립된 품질경영시스템(QMS) 위에서 수행한다. *(향후 연계: [[ISO 13485 MDQMS]])*
2. **역할·역량 보증** — 본 표준이 요구하는 활동마다 책임 역할을 지정·문서화하고, 해당 역할이 적절한 보안 전문성을 갖추도록 교육·평가 프로그램을 운영한다.
3. **공급망 보안 책임** — 제조자 전용·특정 목적으로 개발되고 보안에 영향을 줄 수 있는 제3자 SOFTWARE ITEM 에 대해 보안 요구를 전달하고 보안 활동 수행을 보장한다.
4. **지속개선과 투명성** — 보안 개발 수명주기를 지속적으로 개선하고, 식별된 취약점을 규제기관·사용자에게 적시·투명하게 통지한다.
5. **추적 가능한 종결** — 모든 보안 이슈·오류·누락은 식별·특성화부터 종결까지 추적 가능하게 관리한다.

## 4. 역할과 책임
| 역할 | 책임 |
|---|---|
| **경영책임자(Top Management)** | 본 방침 승인, QMS·자원·역량 확보 |
| **보안책임자(PSO)** | 방침 유지·유효성 검토(연 1회 이상), 보안 수명주기 총괄 |
| **보안운영위원회(PSGB)** | 적용성 결정, 정기 검토, 테일러링·공개 결정 심의 |
| **보안 프로세스 오너** | 담당 프로세스(개발/유지보수/형상/문제해결) 실행·기록 유지 |
| **제품 리스크 관리자** | 보안 리스크의 제품 리스크 관리 통합 *(향후 연계: [[ISO 14971 MDRM]])* |
| **모든 개발·검증 인력** | 지정된 보안 활동 수행, 보안 코딩·설계 모범사례 준수 |

## 5. 준수 기준
- 보안 수명주기 적용 제품 범위, 역할 배정, 제3자 SW 분류(MAINTAINED/SUPPORTED/REQUIRED)는 문서화하여 유지한다. (4.1.3, 4.1.2, 4.3)
- 보안 이슈 관리 프로세스는 **최소 연 1회** 또는 QMS 모니터링·측정·분석의 일부로 정기 검토한다. (4.1.8) *(명시 인용: ISO 13485:2016 §4.1.3)*
- 동반문서(ACCOMPANYING DOCUMENTATION)의 보안 관련 오류·누락은 식별·종결 추적한다. (4.1.9)
- 모든 문서는 [[02_문서번호체계]] 파일명 규칙 및 [[01_문서체계]] 필수 메타를 준수한다.
