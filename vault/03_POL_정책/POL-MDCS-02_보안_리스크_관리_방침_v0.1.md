# 헬스SW 보안 리스크 관리 방침 (POL-MDCS-02)

> 상위 기준: [[표준프로세스_구성원칙]] · 적용요건: [[적용요건]]
> 영역: **MDCS** · Layer: **L2_engineering** · Integration mode: **interface_only**

## 1. 목적
본 방침은 헬스SW 제품에 내재하거나 운영 환경에서 발생할 수 있는 **보안 리스크**를 위협 모델링 기반으로 식별·추정·평가·통제하고, 출시 후 통제 효과를 모니터링하기 위한 방향과 리스크 수용 원칙을 정의한다.

## 2. 적용 범위
보안 수명주기가 적용되는 모든 헬스SW 제품의 자산(기밀성·무결성·가용성)에 영향을 줄 수 있는 취약점·위협에 적용한다. 본 방침의 보안 리스크 관리는 **제품 리스크 관리 접근의 일부**로 수행하며, 안전·유효성과의 연계는 제품 리스크 관리와 협력한다. *(향후 연계: [[ISO 14971 MDRM]])*

## 3. 정책 원칙
1. **위협 모델링 기반** — 보안 리스크는 위협 모델링으로 식별하고, 의도된 사용·사용 환경(PRODUCT SECURITY CONTEXT)을 고려하여 추정·평가한다.
2. **명시적 수용 기준** — 각 취약점 대응 방안 결정에 적용할 **보안 리스크 수용 기준**을 사전에 확립·문서화한다.
3. **잔여 리스크 투명성** — 잔존하는 취약점의 잔여 리스크와 적용된 보완 통제를 문서화하고 릴리스 문서로 전달한다.
4. **제품 RM 통합** — 보안 잔여 리스크 처리는 제품 리스크 관리와 협력하여 수행하고, 안전·유효성 영향을 함께 판정한다.
5. **출시 후 지속 모니터링** — 출시 후 정보 수집·검토를 통해 리스크 통제의 효과를 지속 모니터링한다.

## 4. 역할과 책임
| 역할 | 책임 |
|---|---|
| **경영책임자** | 본 방침 및 리스크 수용 기준 승인 |
| **보안책임자(PSO)** | 보안 리스크 관리 프로세스 총괄, 수용 기준 유지 |
| **위협 모델링 리드** | 위협 모델 작성·검토·갱신 주관 |
| **제품 리스크 관리자** | 보안 리스크의 제품 RM 파일 통합, 안전·유효성 영향 판정 *(향후 연계: MDRM)* |
| **보안 검증 인력** | 통제 조치 효과 검증, 출시 후 모니터링 |

## 5. 준수 기준
- 보안 리스크 수용 기준은 문서화하여 유지하고, 취약점 대응 결정 시 일관되게 적용한다. (4.2-REQ-002)
- 모든 제품은 현재 개발 범위에 특화된 위협 모델을 보유하며 **최소 연 1회** 정기 검토·갱신한다. (7.2)
- 잔여 리스크와 보완 통제는 리스크 관리 파일 및 릴리스 문서에 문서화한다. (4.2-REQ-004)
