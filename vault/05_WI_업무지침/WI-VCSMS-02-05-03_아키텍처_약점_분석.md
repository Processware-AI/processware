# 아키텍처 약점 분석 (WI-VCSMS-02-05-03)

> 상위 절차: [[PRO-VCSMS-02-05_제품개발_사이버보안_엔지니어링_절차]] · 상위 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
사이버보안 사양에 따른 아키텍처 설계에서 약점(weakness)을 식별·분석하여, 사양 검증·통합·검증 이전에 설계 결함을 조기에 발견하고 처리 또는 사양 보완으로 연결한다.

## 2. 수행 주체
- **주 수행자**: 보안 설계자
- **검토자**: Project CS Lead, 개발자
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
ISO/SAE 21434 §10.4.1([RQ-10-07])에 적용한다. 본 약점 분석은 아키텍처 설계 단계 약점 식별이며, 운영 단계 약점·취약점 식별([[PRO-VCSMS-01-03_지속적_사이버보안_활동_및_취약점_관리_절차]])과 구별된다. 식별 약점은 사양 검증(WI-05-04)·테스트(WI-05-06)로 추적한다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-05-01-01_사이버보안_사양서]] (할당 사양·아키텍처)
  - 코딩 기준 적용 확인서(WP-10-03)의 미시정 잔존 위반·잔존 제약([[WI-VCSMS-02-05-02_설계_구현_원칙_및_언어_코딩_기준_적용]])
- **Output**
  - [[TMP-VCSMS-02-05-03-01_아키텍처_약점_분석서]] 작성분 (WP-10-05)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 사양서(WP-10-01)·아키텍처가 확정(WI-05-01 done) 상태인지 확인한다(entry_gate).
2. WI-05-02 에서 등록된 잔존 위반·제약을 약점 후보로 수집한다.
3. 약점 분석서 양식([[TMP-VCSMS-02-05-03-01_아키텍처_약점_분석서]])을 발번한다.

### 5.2 수행 단계
1. **분석 방법 선정**
   - 아키텍처 검토·약점 카탈로그(CWE 등) 매핑·STRIDE 등 분석 방법을 선정한다.
2. **약점 식별** ([RQ-10-07])
   - 컴포넌트·인터페이스·신뢰경계별로 약점(WK-##)을 식별한다.
   - WI-05-02 잔존 위반·제약을 약점 후보로 포함한다.
3. **약점 영향·관련 사양 연결**
   - 각 약점이 어떤 사양·자산·신뢰경계에 영향을 주는지 연결한다.
4. **처리 방향 결정**
   - 약점별로 설계 변경·사양 보완·테스트 검증 대상·수용(근거) 중 처리 방향을 결정한다.
   - 사양 보완 필요 시 WI-05-01 로 피드백한다.
5. **검토·승인**
   - Project CS Lead·개발자 검토를 반영하고 CSM 승인을 받는다.

### 5.3 완료 조건
- [ ] entry_gate(WI-05-01 done) 충족 확인
- [ ] 분석 방법 선정·기록
- [ ] 컴포넌트·인터페이스·신뢰경계 약점 식별 완료
- [ ] WI-05-02 잔존 위반·제약 약점 후보 반영
- [ ] 각 약점에 처리 방향 결정(미결 0)
- [ ] CSM 승인 기록 확보

## 6. 인터페이스 부서
- **개발자/보안 설계자**: 사양 보완 필요 시 WI-05-01 로 피드백
- **검증 엔지니어**: 테스트 검증 대상 약점을 WI-05-06 으로 인계
- **운영팀**: 운영 약점 관리와 분리 확인([[PRO-VCSMS-01-03_지속적_사이버보안_활동_및_취약점_관리_절차]])

## 7. 주의사항 / 예외 처리

### 7.1 약점→사양 보완 루프
- 약점이 사양 자체의 결함에서 비롯되면, 본 분석을 중단하지 말고 WI-05-01 로 사양 보완을 요청한 뒤 보완 사양으로 약점을 재분석한다.

### 7.2 약점 수용(처리 불가)
- 설계 변경이 불가하여 약점을 수용하는 경우, 잔여 리스크 근거와 보상통제(테스트·런타임 보호)를 명시하고 CSM 수용 결정을 받는다.

### 7.3 운영 약점 혼입
- 운영 단계에서 식별될 약점(현장 모니터링 대상)이 혼입되면, 운영 절차([[PRO-VCSMS-01-03_지속적_사이버보안_활동_및_취약점_관리_절차]])로 이관하고 본 분석서에서는 참조만 남긴다.
