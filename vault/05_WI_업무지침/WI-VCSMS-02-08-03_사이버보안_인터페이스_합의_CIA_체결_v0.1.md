# 사이버보안 인터페이스 합의(CIA) 체결 (WI-VCSMS-02-08-03)

> 상위 절차: [[PRO-VCSMS-02-08_분산_사이버보안_활동_및_공급망_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
고객과 공급자 간에 분산되는 사이버보안 활동과 그 책임을 **사이버보안 인터페이스 합의(CIA, Cybersecurity Interface Agreement)** 에 명시하고, 활동 개시 전에 상호 합의·서명한다. CIA 는 분산 활동의 책임 경계를 정의하는 기준 문서다. (VCSMS-R-055 / [RQ-07-04], VCSMS-R-056 / [RC-07-05])

## 2. 수행 주체
- **주 수행자**: Project CS Lead
- **검토자**: 조달 담당·법무
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
PRO-VCSMS-02-08 §5 단계 3(CIA 체결)에 적용한다. 선행 WI-VCSMS-02-08-02(RFQ)가 완료된 후 착수한다(entry gate). 계약 일반 조항·상거래 조건은 상위 법무·조달(인터페이스 대상)이 다루고, 본 지침은 CIA 의 사이버보안 활동·책임 명시·합의만 다룬다.

## 4. 입력 자료 / 산출물
- **Input**
  - 발행된 RFQ 와 공급자 견적·제안
  - [[TMP-VCSMS-02-08-02-01_RFQ_사이버보안_요건_체크리스트]] (목표/요구·보완 요구)
  - 공급 대상 활동의 전체 작업 분해(WBS)와 사이버보안 활동 목록
- **Output**
  - [[TMP-VCSMS-02-08-03-01_사이버보안_인터페이스_합의서_CIA]] 작성·서명분 (WP-07-01)
  - 책임 분배 결과(다음 WI-08-04 입력)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 분산 대상 사이버보안 활동을 빠짐없이 목록화한다(개발·검증·취약점 관리·인시던트 대응·산출물 인계).
2. RFQ 요건·공급자 제안을 대조하여 책임 분배 초안의 근거를 확보한다.
3. 취약점 식별 시 조치·책임 합의 규칙([RQ-08-07] 연계)을 CIA 에 포함할 항목으로 준비한다.

### 5.2 수행 단계
1. **활동·책임 명시**
   - 각 사이버보안 활동에 대해 고객/공급자 책임(R/A/C/I)을 CIA 에 명시한다. (VCSMS-R-055 / [RQ-07-04])
   - 산출물 인계 시점·형식, 요구 충족 증빙 책임을 명시한다.
2. **취약점·인시던트 책임 규칙**
   - 관리 대상 취약점 식별 시 고객·공급자가 조치·책임을 합의하는 규칙을 포함한다. (VCSMS-R-057 / [RQ-07-06])
   - 인시던트 발생 시 상호 통지·협조 책임을 명시한다.
3. **요구 불명확·충돌 통지 규칙**
   - 요구가 불명확·비현실·충돌할 때 상호 통지로 적절한 결정·조치가 가능하도록 통지 채널·기한을 정의한다. (VCSMS-R-058 / [RQ-07-07])
4. **상호 검토·합의**
   - 고객·공급자가 CIA 초안을 상호 검토하고 이견을 조정한다.
   - **활동 개시 전** 상호 서명으로 합의를 확정한다. (VCSMS-R-056 / [RC-07-05])
5. **CSM 승인·발효**
   - CSM 이 책임 경계의 완전성을 검토·승인한다.
   - 서명 완료된 CIA 를 발효하고, 책임 분배 결과를 WI-08-04(책임 운영)로 인계한다.

### 5.3 완료 조건
- [ ] 분산 대상 사이버보안 활동이 빠짐없이 CIA 에 목록화되었다
- [ ] 각 활동의 고객/공급자 책임이 명시되었다
- [ ] 취약점·인시던트 시 조치·통지 책임 규칙이 포함되었다
- [ ] 요구 불명확·충돌 시 상호 통지 규칙이 정의되었다
- [ ] 활동 개시 전 고객·공급자 상호 서명이 완료되었다
- [ ] CSM 검토·승인 후 CIA 가 발효되었다

## 6. 인터페이스 부서
- **법무/조달**: 계약 구속력·일반 조항 정합
- **공급자**: 책임 합의 당사자
- **CSM 조직**: 책임 경계 완전성 검토

## 7. 주의사항 / 예외 처리

### 7.1 활동 개시 후 CIA 체결(역순 발생)
- 일정 압박으로 활동이 CIA 합의 전에 개시될 위험이 있으면, 임시 책임 합의서(잠정 CIA)를 서명하고 정식 CIA 를 정해진 기한 내 체결한다. 잠정 기간의 책임 공백을 CSM 이 명시적으로 수용 기록한다. (원칙: VCSMS-R-056 활동 개시 전 합의)

### 7.2 책임 분배 미합의 항목 잔존
- 일부 활동의 책임이 끝내 합의되지 않으면 해당 활동을 개시하지 않는다. 미합의 항목을 목록화하고 에스컬레이션(CSM↔공급자 경영층)하여 합의 후 개시한다.

### 7.3 다단계 공급망(N-tier)
- 공급자가 재하청(서브 공급자)에 활동을 재분산하는 경우, 공급자가 서브 공급자와 CIA 를 체결하고 그 책임이 본 CIA 와 일관됨을 보증하도록 본 CIA 에 흐름 다운(flow-down) 조항을 둔다.
