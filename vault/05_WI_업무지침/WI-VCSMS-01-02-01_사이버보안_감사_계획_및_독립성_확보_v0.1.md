# 사이버보안 감사 계획 및 독립성 확보 (WI-VCSMS-01-02-01)

> 상위 절차: [[PRO-VCSMS-01-02_독립_조직_사이버보안_감사_절차]] · 상위 정책: [[POL-VCSMS-01_자동차_사이버보안_거버넌스_정책]]

## 1. 업무 목적
조직의 사이버보안 프로세스가 ISO/SAE 21434 목적을 달성하는지를 판정하기 위한 **독립적 사이버보안 감사를 계획**한다. 범위·기준·일정·심사원을 정하고, **감사인이 피감 활동의 실행 책임을 갖지 않도록 독립성을 확보**한다.

## 2. 수행 주체
- **주 수행자**: Auditor (감사인)
- **검토자**: Cybersecurity Manager (CSM) — 독립성 확인
- **승인자**: 경영진 (Top Management) — 감사 계획 승인

## 3. 범위
PRO-VCSMS-01-02 §5 단계 1·2 에 적용한다. 감사 계획(범위·기준·일정·심사원 선정)과 독립성 확인(auditor ≠ executor, §5.4.7 [RQ-05-17])을 다룬다. 내부심사 거버넌스(심사원 자격·독립성 일반 기준)는 상위 §9.2 를 참조한다(interface_only). 프로젝트 차원 사이버보안 평가(§6.4.8)는 본 절차 범위 밖이며 PRO-VCSMS-02-02 로 분리한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 조직 사이버보안 거버넌스 산출물(PRO-VCSMS-01-01 의 WP-05-01~04)
  - 사이버보안 프로세스 목록(거버넌스·지속활동·사고대응·프로젝트)
  - 심사원 후보 이력·역할 배정표
  - ISO/SAE 21434 §5.4.7 [RQ-05-17] 요건, 상위 §9.2 내부심사 기준
- **Output**
  - 사이버보안 감사 계획서(범위·기준·일정·심사원)
  - 독립성 확인 기록(auditor ≠ executor)
  - [[TMP-VCSMS-01-02-01-01_사이버보안_감사계획서]] 작성분

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 감사 주기 확인(KPI: 연 1회 이상)과 직전 감사 결과·미종결 조치 수집.
2. 피감 대상 프로세스 범위 확정(거버넌스·지속활동·사고대응·프로젝트 관리).
3. 심사원 후보 목록과 각 후보의 실행 책임 이력 확보(독립성 판단 근거).

### 5.2 수행 단계
1. **감사 범위·기준 정의**
   - 감사 범위(대상 프로세스·기간)와 적합성 판정 기준(ISO/SAE 21434 조항·조직 규칙)을 정의.
   - 표준 목적 달성 여부 판정에 필요한 증거 유형을 명시.
2. **일정·자원 계획**
   - 감사 일정(착수·현장·보고), 인터뷰 대상, 필요 증거 접근 권한을 계획.
3. **심사원 선정·독립성 확보** ([RQ-05-17])
   - 각 심사원이 피감 프로세스의 실행 책임이 없음을 확인(auditor ≠ executor).
   - 이해상충 시 심사원 교체 또는 외부 감사인 위촉.
   - [[TMP-VCSMS-01-02-01-01_사이버보안_감사계획서]] 의 독립성 확인 섹션에 근거 기록.
4. **CSM 독립성 검토**
   - CSM 이 심사원 배정의 독립성을 검토·확인(피감 조직과의 보고선·이해관계 점검).
5. **경영진 승인**
   - 감사 계획서를 경영진에게 승인 요청. 독립성 미확보 시 계획 보류.
6. **통지·준비**
   - 피감 조직에 감사 계획·일정을 통지하고 증거 준비를 요청.

### 5.3 완료 조건
- [ ] 감사 범위·적합성 판정 기준 정의 완료
- [ ] 감사 일정·인터뷰 대상·증거 접근 권한 계획 완료
- [ ] 심사원별 독립성(auditor ≠ executor) 확인 및 근거 기록
- [ ] 이해상충 발생 시 교체·외부 위촉 처리 완료
- [ ] CSM 독립성 검토 통과
- [ ] 경영진 감사 계획 승인 및 피감 조직 통지 완료

## 6. 인터페이스 부서
- **내부심사 사무국(§9.2)**: 심사원 자격·독립성 일반 기준 정본 — 본 지침은 참조
- **경영진**: 감사 계획 승인
- **피감 조직**: 증거 준비·인터뷰 협조

## 7. 주의사항 / 예외 처리

### 7.1 독립성 미확보(인력 부족)
- 내부에 독립 감사인이 없는 경우(소규모 조직):
  - 외부 감사인을 위촉하거나, 차상위 조직·교차 부서 심사원으로 독립성 확보.
  - 독립성 확보 불가 시 감사를 보류하고 경영진에 보고.

### 7.2 감사 범위 축소 요청
- 피감 조직이 범위·증거 접근을 제한하려는 경우:
  - 범위 축소는 감사 무결성을 훼손하므로 거부하고 경영진 권한으로 접근 보장.
  - 불가피한 제한은 한계(limitation)로 보고서에 명시 예고.

### 7.3 감사 주기 미준수
- 정의 주기(연 1회) 내 감사가 계획되지 않은 경우:
  - 즉시 임시 감사를 계획하고 미준수 사유를 거버넌스 개선 기록에 등록.
