# 지원 종료 통보 절차 수립·통보 (WI-VCSMS-02-09-03)

> 상위 절차: [[PRO-VCSMS-02-09_운영_업데이트_및_지원종료_폐기_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
item 또는 component 의 사이버보안 지원 종료가 결정되면, 고객에게 종료 사실·시점·영향을 알리는 통보 절차를 수립하고 실제로 통보한다. 고객이 종료 후 잔존 위험을 인지하고 대응(폐기·교체)할 수 있도록 한다. (VCSMS-R-100 / [RQ-14-01])

> 본 WI 는 선택(mandatory: false) — 지원 종료 결정이 발생하는 경우에만 적용.

## 2. 수행 주체
- **주 수행자**: 고객 소통 담당
- **검토자**: 운영/필드·법무
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
PRO-VCSMS-02-09 §5 단계 3(지원 종료 통보)에 적용한다. 종료 결정 자체(사업·기술 판단)는 상위 제품관리(인터페이스 대상)가 내리며, 본 지침은 사이버보안 관점의 통보 절차 수립·통보·기록만 다룬다. 폐기 관련 요구 제공은 후속 WI-VCSMS-02-09-04 가 담당한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 지원 종료 결정(대상 item/component·종료 예정일)
  - 대상의 영향 고객·차종·VIN 범위
  - 종료 후 잔존 위험·권고 조치(교체·격리·기능 제한)
- **Output**
  - [[TMP-VCSMS-02-09-03-01_지원_종료_통보서]] 작성·발송분 (WP-14-01)
  - 통보 이력(대상·일자·채널·수신 확인)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 지원 종료 대상과 종료 예정일, 영향 고객·차종·VIN 범위를 확정한다.
2. 종료 후 잔존 사이버보안 위험과 고객 권고 조치(폐기·교체·기능 제한)를 정리한다.
3. 통보 채널(공식 서한·딜러망·앱 공지)과 통보 리드타임(법규·계약상 최소 기간)을 확인한다.

### 5.2 수행 단계
1. **통보 절차 수립**
   - 통보 대상·시점·채널·반복 통보·수신 확인 방법을 포함한 통보 절차를 작성한다. (VCSMS-R-100 / [RQ-14-01])
2. **통보서 작성**
   - 통보서에 종료 대상·종료일·잔존 위험·권고 조치·문의 창구를 명확히 기재한다.
3. **검토·승인**
   - 법무(고지 의무)·CSM(잔존 위험 표현 적정성)이 검토하고 CSM 이 승인한다.
4. **통보 실행**
   - 정의된 채널로 통보하고, 통보 일자·수신 확인을 기록한다.
   - 미수신·반송 건은 대체 채널로 재통보한다.
5. **후속 연계**
   - 폐기 관련 post-development 요구 제공(WI-09-04)으로 연계하고, 잔존 위험을 추적 항목으로 등록한다.

### 5.3 완료 조건
- [ ] 지원 종료 대상·예정일·영향 범위가 확정되었다
- [ ] 종료 후 잔존 위험·권고 조치가 정리되었다
- [ ] 통보 절차(대상·시점·채널·수신 확인)가 수립되었다
- [ ] 통보서가 법무·CSM 검토·승인을 거쳐 발송되었다
- [ ] 통보 이력·수신 확인이 기록되고 미수신 재통보가 처리되었다

## 6. 인터페이스 부서
- **제품관리**: 지원 종료 결정·일정
- **법무**: 고지 의무·계약상 통보 요건
- **딜러/CS 채널**: 통보 전달·수신 확인
- **CSM 조직**: 잔존 위험 표현·후속 연계

## 7. 주의사항 / 예외 처리

### 7.1 법규상 최소 통보 기간 미준수 위험
- 종료 결정과 종료일 간 간격이 법규·계약상 최소 통보 기간보다 짧으면, 종료일을 조정하거나 임시 연장 지원을 검토한다. 임의로 기간을 단축하지 않으며, 불가피 시 법무 결정을 기록한다.

### 7.2 통보 미수신(연락처 불일치)
- 통보 대상의 연락처가 불일치하여 수신 확인이 불가하면, 대체 채널(딜러 방문·공개 공지)을 활용하고 미도달 대상을 잔존 위험으로 추적한다. 도달 노력을 기록한다.

### 7.3 종료 후 신규 취약점 발견
- 지원 종료 후 해당 item 에서 신규 취약점이 발견되면, 통보서에 명시한 잔존 위험 한계와 권고 조치(교체·격리)를 재안내하고, 사고 가능성은 사고 대응(PRO-VCSMS-01-04) 연계 여부를 CSM 이 판정한다.
