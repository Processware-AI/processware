# 보안 코딩 구현 및 구현 검토(정적분석) (WI-MDCS-01-02-05)

> 상위 절차: [[PRO-MDCS-01-02_보안_SW_개발_프로세스_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
보안 설계를 보안 코딩 표준을 준수하여 구현하고, 정적분석(SCA)·코드 검토로 코딩 표준 편차와 보안 약점을 식별하며, 설계-구현 추적성을 확인하고 발견된 보안 이슈를 문제해결 프로세스로 연계하여, 안전한 코드 베이스를 확보한다. (5.5.1, 5.5.2)

## 2. 수행 주체
- **주 수행자**: 개발자
- **검토자**: 검토자(독립)
- **승인자**: 검토자(독립)

## 3. 범위
PRO-MDCS-01-02 §5 단계5(구현)에 적용한다. **선행조건**: WI-MDCS-01-02-04(설계) 완료. 각 빌드·머지 시 SCA 를 실행한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 상세 보안 설계(WI-MDCS-01-02-04)
  - 보안 코딩 표준(WI-MDCS-01-02-01)
  - 정적분석(SCA) 도구·룰셋
- **Output**
  - [[TMP-MDCS-01-02-05-01_구현검토_및_정적분석_보고서_v0.1]] 작성분
  - 구현 코드(보안 코딩 표준 준수)
  - 정적분석 보고서
  - 구현 검토 기록(편차·추적성·이슈 연계)

## 5. 수행 절차

### 5.1 사전 준비
1. 설계 문서·보안 코딩 표준을 확인한다.
2. SCA 도구·룰셋을 빌드 파이프라인에 통합한다.

### 5.2 수행 단계
1. **보안 코딩 구현**
   - 설계를 보안 코딩 표준에 따라 구현한다(입력 검증·암호 사용·에러 처리).
2. **정적분석(SCA) 실행**
   - 빌드/머지 시 SCA 를 실행하고 발견 항목을 심각도별로 분류한다.
3. **구현 검토(코드 리뷰)**
   - 독립 검토자가 코딩 표준 편차·보안 약점·설계 추적성을 검토한다.
4. **이슈 처리·연계**
   - 발견된 보안 이슈는 시정하거나 PRO-MDCS-01-05(문제해결)로 연계한다.
   - 고위험 항목은 종결 전 다음 단계 진행을 보류한다.
5. **검토 승인**
   - 독립 검토자가 편차 종결·고위험 이슈 종결을 확인·승인한다.

### 5.3 완료 조건
- [ ] 구현이 보안 코딩 표준을 준수함(편차 시정 또는 정당화)
- [ ] 빌드 대비 SCA 실행률 100%
- [ ] SCA 고위험 항목 0건(시정 또는 문제해결 연계 종결)
- [ ] 설계-구현 추적성 확인
- [ ] 보안 이슈가 문제해결 프로세스로 연계·추적됨
- [ ] 독립 검토자 검토·승인 기록 존재

## 6. 인터페이스 부서
- **DevOps**: CI 파이프라인 SCA 통합
- **PRO-MDCS-01-05(문제해결)**: 발견 이슈 연계
- **WI-MDCS-01-02-07(시스템 시험)**: 구현물 이관

## 7. 주의사항 / 예외 처리

### 7.1 SCA 오탐(false positive)
- SCA 오탐으로 판정된 항목은 근거를 기록하고 억제(suppress)하되, 억제 항목은 검토자 승인을 받는다(무분별 억제 금지).

### 7.2 코딩 표준 편차 정당화
- 불가피한 코딩 표준 편차는 사유·보완 통제를 기록하고 검토자가 승인한다. 정당화 없는 편차는 시정한다.

### 7.3 고위험 이슈 미종결
- SCA/검토 고위험 이슈가 종결되지 않으면 다음 단계(시험·릴리스) 진행을 보류하고 PRO-MDCS-01-05 로 처리한다.

### 7.4 외부 라이브러리 취약점
- 의존성 스캔에서 외부 라이브러리 취약점이 발견되면 업그레이드·대체·격리 중 선택하고, MAINTAINED 항목은 PRO-MDCS-01-03 모니터링에도 반영한다.
