# 취약점 관리 및 처리 결정 (WI-VCSMS-01-03-05)

> 상위 절차: [[PRO-VCSMS-01-03_지속적_사이버보안_활동_및_취약점_관리_절차]] · 상위 정책: [[POL-VCSMS-01_자동차_사이버보안_거버넌스_정책]]

## 1. 업무 목적
식별된 취약점별로 **처리 방식을 결정**하여 관리한다. 리스크 처리가 필요하면 TARA(§15.9)를 호출하고, TARA 와 무관하게 즉시 제거 가능하면 즉시 시정한다. 처리 결정이 **사고 대응을 요하면 사고대응(§13.3)을 연계**한다.

## 2. 수행 주체
- **주 수행자**: Cybersecurity Manager (CSM)
- **검토자**: 보안 분석가 (Security Analyst)
- **승인자**: Cybersecurity Manager (CSM) — 처리 결정 권한

## 3. 범위
PRO-VCSMS-01-03 §5 단계 5·6 에 적용한다. 취약점 관리(§15.9 리스크 처리 또는 즉시 제거, §8.6 [RQ-08-07]), 사고대응 연계 판단([RQ-08-08])을 다룬다. 취약점 식별은 선행 [[WI-VCSMS-01-03-04_약점_분석_및_취약점_식별]] 전제(entry_gate). 리스크 처리 실행은 TARA([[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]]), 사고대응은 [[PRO-VCSMS-01-04_사이버보안_사고_대응_절차]] 가 담당한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 식별된 취약점([[WI-VCSMS-01-03-04_약점_분석_및_취약점_식별]] 산출물)
  - 영향 자산·잠정 영향·악용 가능성
  - (해당 시) 기존 TARA 리스크값·처리 옵션
  - ISO/SAE 21434 §8.6 [RQ-08-07·08] 요건
- **Output**
  - 취약점 처리 결정(리스크 처리 호출 / 즉시 제거)
  - 즉시 제거 시정 기록 또는 TARA 호출 기록
  - 사고대응 연계 판단·기록
  - 취약점 처리 결정·관리대장 (WP-08-06) — [[TMP-VCSMS-01-03-05-01_취약점_처리_결정_및_관리대장]] 작성분

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. entry_gate 확인: WI-VCSMS-01-03-04 가 `done`(취약점 식별·승인) 인지 확인.
2. 취약점별 영향·악용 가능성·관련 자산을 정리하고 처리 시급성을 평가.

### 5.2 수행 단계
1. **처리 방식 결정** ([RQ-08-07])
   - 취약점별로 처리 경로를 결정:
     - (a) 리스크 처리 필요 → TARA(§15.9, [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]]) 호출.
     - (b) TARA 무관 즉시 제거 가능(명백한 결함·통제 적용) → 즉시 시정.
   - 결정 근거를 [[TMP-VCSMS-01-03-05-01_취약점_처리_결정_및_관리대장]] 에 기록.
2. **TARA 호출 (경로 a)**
   - 리스크 처리 대상 취약점을 TARA 절차로 전달(자산·위협 시나리오·잠정 영향 포함).
   - TARA 결과(리스크값·처리 옵션)를 수신하여 관리대장에 환류.
3. **즉시 제거 (경로 b)**
   - 즉시 시정 조치(패치·구성 변경·통제 적용)를 정의·실행하고 유효성을 확인.
4. **사고대응 연계 판단** ([RQ-08-08])
   - 처리 결정이 사고 대응을 요하는지(악용 진행·현장 영향) 판단하고, 필요 시 [[PRO-VCSMS-01-04_사이버보안_사고_대응_절차]] 가동.
5. **CSM 처리 결정 승인**
   - CSM 이 처리 경로·시정·연계 판단을 승인하고 책임자·완료 기준을 확정.
6. **추적·종결**
   - 처리 진척을 추적하고 완료(KPI: 취약점 처리 완료율 ≥ 95%) 시 종결·관리대장 갱신.

### 5.3 완료 조건
- [ ] 취약점별 처리 경로(TARA 호출 / 즉시 제거) 결정 및 근거 기록
- [ ] 경로 a: TARA 호출·결과(리스크값·옵션) 환류
- [ ] 경로 b: 즉시 시정 조치 실행·유효성 확인
- [ ] 사고대응 연계 필요성 판단 및 (해당 시) 가동
- [ ] CSM 처리 결정 승인·책임자·완료 기준 확정
- [ ] 처리 추적·종결(완료율 ≥ 95%) 및 관리대장 갱신

## 6. 인터페이스 부서
- **TARA 운영(PRO-VCSMS-02-03)**: 리스크 처리 호출 대상
- **사고대응(PRO-VCSMS-01-04)**: 사고 연계 대상
- **설계/개발·생산**: 시정 조치 실행
- **공급망(§7)**: 공급사 컴포넌트 취약점 조치 책임 합의

## 7. 주의사항 / 예외 처리

### 7.1 처리 경로 판단 모호
- TARA 호출과 즉시 제거 중 어느 경로인지 모호한 경우:
  - 잠정 영향이 안전(S)에 닿거나 리스크가 불확실하면 TARA 호출을 기본으로 선택.
  - 판단 근거를 관리대장에 기록.

### 7.2 즉시 제거 불가·장기화
- 즉시 시정이 불가하거나 장기화되는 경우:
  - 임시 완화책(통제 강화·기능 제한)을 적용하고 잔존 리스크를 명시.
  - 근본 시정 일정과 함께 TARA 로 재평가.

### 7.3 대규모·현장 영향(리콜·OTA)
- 취약점이 현장 차량에 광범위 영향(리콜·대규모 OTA)을 미치는 경우:
  - 사고대응(PRO-01-04)·운영 업데이트(PRO-02-09)를 연계하고 경영진·규제 통보를 가동.
