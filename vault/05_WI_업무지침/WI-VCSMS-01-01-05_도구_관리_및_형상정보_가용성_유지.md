# 도구 관리 및 형상정보 가용성 유지 (WI-VCSMS-01-01-05)

> 상위 절차: [[PRO-VCSMS-01-01_조직_사이버보안_거버넌스_운영_절차]] · 상위 정책: [[POL-VCSMS-01_자동차_사이버보안_거버넌스_정책]]

## 1. 업무 목적
item/component 의 사이버보안에 **영향을 줄 수 있는 도구를 식별·관리**하고, 현장 제품의 사이버보안 유지에 필요한 **형상정보를 지원종료 시점까지 가용하게 유지**한다. 도구로 인한 약점 유입을 방지하고, 사고 시정조치에 필요한 환경을 재현 가능하게 보존한다.

## 2. 수행 주체
- **주 수행자**: Process Owner
- **검토자**: Cybersecurity Manager (CSM)
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
PRO-VCSMS-01-01 §5 단계 8 에 적용한다. 도구 관리(§5.4.5 [RQ-05-14]), 형상정보 가용성 유지(§5.4.4 [RQ-05-12]), 시정조치 환경 재현 보존(§5.4.4 [RC-05-15], should)을 다룬다. **변경·문서·형상·요구사항 관리 일반 메커니즘은 상위 QMS(§5.4.4 [RQ-05-11])를 참조**하며, 본 지침은 사이버보안 영향 도구·형상정보 특화 항목만 다룬다(interface_only). 본 WI 는 `mandatory: false`(조직 컨텍스트에 따라 적용).

## 4. 입력 자료 / 산출물
- **Input**
  - 사이버보안 엔지니어링 도구 인벤토리(설계·분석·테스트·빌드·배포 도구)
  - 제품 형상정보(SW/HW 버전·키·인증서·구성)
  - ISO/SAE 21434 §5.4.4·5.4.5 [RQ-05-12·14], [RC-05-15] 요건
  - 상위 QMS 형상관리 정책(§5.4.4 참조)
- **Output**
  - 사이버보안 도구·형상정보 관리대장 (WP-05-04)
  - 도구 영향 평가·관리 조치 기록
  - 형상정보 가용성 유지 계획(지원종료까지)
  - [[TMP-VCSMS-01-01-05-01_사이버보안_도구_및_형상정보_관리대장]] 작성분

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. entry_gate 확인: WI-VCSMS-01-01-01 이 `done`(정책 승인) 인지 확인.
2. 적용 여부 판단: 본 WI 는 mandatory:false 이므로, 조직이 사이버보안 영향 도구·형상정보 관리를 자체 수행하는지(또는 상위 QMS 가 충분히 커버하는지) 판단.
3. 도구 인벤토리·형상정보 목록 확보.

### 5.2 수행 단계
1. **사이버보안 영향 도구 식별** ([RQ-05-14])
   - 인벤토리에서 item/component 사이버보안에 영향을 줄 수 있는 도구를 식별(약점 유입·검증 누락 가능 도구).
   - 각 도구의 영향 유형(설계·구현·검증·배포)·신뢰 근거(검증·자격·이력)를 기록.
2. **도구 관리 조치**
   - 도구별 관리 조치 정의: 버전 고정, 무결성 검증, 설정 통제, 변경 시 재평가.
   - [[TMP-VCSMS-01-01-05-01_사이버보안_도구_및_형상정보_관리대장]] 에 도구·영향·조치를 기록.
3. **형상정보 식별·보존 계획** ([RQ-05-12])
   - 현장 제품 사이버보안 유지에 필요한 형상정보(버전·키·인증서·빌드 구성)를 식별.
   - 지원종료 시점까지의 보존 매체·접근통제·갱신 책임을 정의.
4. **시정조치 환경 재현 보존** ([RC-05-15], should)
   - 사고 시정조치(패치·재빌드)에 필요한 개발·빌드 환경을 재현 가능하게 보존(도구 체인·소스·구성 스냅샷).
5. **검토·승인**
   - CSM 이 도구 관리 충분성과 형상정보 보존 계획의 지원종료 커버리지를 검토·승인.
6. **운영·점검**
   - 관리대장을 운영하고, 미관리 사이버보안 영향 도구(KPI: 0건)·형상정보 가용성을 분기 점검.

### 5.3 완료 조건
- [ ] 본 WI 적용 여부 판단(자체 수행 vs 상위 QMS 커버) 기록
- [ ] 사이버보안 영향 도구 식별 및 영향 유형·신뢰 근거 기록
- [ ] 도구별 관리 조치(버전 고정·무결성·변경 재평가) 정의
- [ ] 지원종료까지 형상정보 보존 매체·접근통제·책임 정의
- [ ] 시정조치 환경 재현 보존 방안(권고) 검토
- [ ] CSM 검토·승인 및 분기 점검 체계 운영(미관리 도구 0건)

## 6. 인터페이스 부서
- **QMS/형상관리(§5.4.4)**: 변경·형상·문서 관리 정본 — 본 지침은 사이버보안 영향 항목만
- **IT/인프라**: 도구 체인·보존 매체·백업 운영
- **개발/검증 부서**: 도구 사용·영향 평가 협조

## 7. 주의사항 / 예외 처리

### 7.1 상위 QMS 가 충분히 커버 (mandatory:false 분기)
- 상위 QMS 형상관리가 사이버보안 영향 도구·형상정보를 충분히 관리하는 경우:
  - 본 영역은 별도 관리대장 대신 QMS 대장을 "참조"하고, 사이버보안 특화 항목(키·인증서 등)만 보강.
  - 판단 근거를 기록하고 본 WI 는 경량 운영.

### 7.2 도구 변경에 따른 재평가 누락
- 사이버보안 영향 도구의 버전·설정이 변경되었으나 재평가가 누락된 경우:
  - 즉시 영향 재평가를 트리거하고 결과를 관리대장에 반영.
  - 변경 통제 게이트에 도구 재평가를 연동.

### 7.3 형상정보 가용성 위험(매체 노후·접근 상실)
- 보존 매체 노후·접근권 상실로 형상정보 가용성이 위협받는 경우:
  - 매체 이전·재백업을 즉시 수행하고 접근권을 재정비.
  - 가용성 리스크를 CSM 에 보고하고 보존 계획을 갱신.
