# 평가 보고서 작성 (WI-VCSMS-02-02-04)

> 상위 절차: [[PRO-VCSMS-02-02_사이버보안_케이스_평가_및_릴리스_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
독립 평가 결과를 보고서(WP-06-03)로 정리하여 수용/조건부 수용/거부 권고를 제시하고, 조건부 수용 시 수용 조건을 명시함으로써, 릴리스 결정의 근거를 제공한다. (§6.4.8 [RQ-06-31,32])

## 2. 수행 주체
- **주 수행자**: Assessor(독립)
- **검토자**: Cybersecurity Manager (CSM)
- **승인자**: Assessor(독립) — 권고의 독립적 책임

## 3. 범위
본 지침은 PRO-VCSMS-02-02 §5 단계 5(평가 보고)에 적용한다. mandatory=false(평가 수행 시에만). 보고서는 독립평가 체크리스트(WI-03)의 발견사항을 종합한다. 릴리스 결정은 WI-VCSMS-02-02-05 로 이어진다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-02-03-01_독립평가_체크리스트]] (작성 완료)
  - 사이버보안 케이스 및 발견사항
- **Output**
  - [[TMP-VCSMS-02-02-04-01_사이버보안_평가보고서]] 작성분 (WP-06-03, 권고+조건)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 독립평가 체크리스트가 완료되었는지 확인한다(entry_gate).
2. 항목별 결과(적합/조건부/부적합)와 발견사항을 종합한다.

### 5.2 수행 단계
1. **발견사항 종합**
   - 체크리스트의 부적합·조건부 항목을 우선순위와 함께 정리한다.
2. **권고 결정**
   - 종합 결과에 따라 수용 / 조건부 수용 / 거부 중 하나를 권고한다([RQ-06-31]).
   - 부적합 중대 항목이 있으면 거부, 닫을 수 있는 조건이면 조건부 수용.
3. **수용 조건 명시 (조건부 시)**
   - 조건부 수용 권고 시 충족해야 할 수용 조건과 검증 방법·기한을 명시한다([RQ-06-32]).
4. **보고서 확정·전달**
   - Assessor 가 보고서를 확정·서명하고 CSM·릴리스 결정권자에게 전달한다.

### 5.3 완료 조건
- [ ] 발견사항(부적합·조건부) 종합·우선순위화
- [ ] 수용/조건부/거부 권고 결정
- [ ] (조건부 시) 수용 조건·검증 방법·기한 명시
- [ ] Assessor 서명·확정
- [ ] CSM·릴리스 결정권자 전달

## 6. 인터페이스 부서
- **CSM/프로젝트팀**: 보고서 수신·조건 이행
- **품질(QMS)**: 보고서 형상·문서 관리 (§5.4.4 경계면)

## 7. 주의사항 / 예외 처리

### 7.1 조건 모호
- 조건부 수용 조건이 모호하거나 검증 불가능한 경우:
  - 조건을 측정 가능·검증 가능한 형태로 재작성.
  - 모호 조건으로 릴리스 게이트 통과 금지.

### 7.2 거부 후 재평가
- 거부 권고 후 보완·재작업이 완료된 경우:
  - 변경된 케이스로 재평가(WI-03)를 거쳐 신규 보고서를 발행.
  - 이전 거부 보고서는 이력으로 보존.

### 7.3 권고와 결정권자 이견
- 릴리스 결정권자가 거부/조건부 권고를 무시하려는 경우:
  - 권고 무시 결정은 경영진 명시 승인·근거 기록을 필수 조건으로 함.
  - Assessor 의 독립 의견은 보고서에 원형 보존.
