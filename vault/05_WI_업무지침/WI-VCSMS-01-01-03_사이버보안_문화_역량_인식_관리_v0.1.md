# 사이버보안 문화·역량·인식 관리 (WI-VCSMS-01-01-03)

> 상위 절차: [[PRO-VCSMS-01-01_조직_사이버보안_거버넌스_운영_절차]] · 상위 정책: [[POL-VCSMS-01_자동차_사이버보안_거버넌스_정책]]

## 1. 업무 목적
조직 내 **견고한 사이버보안 문화**를 조성·유지하고, 사이버보안 역할 담당자의 **역량과 인식**을 보장한다. 역량 미흡을 식별·보완하고 전사 인식 수준을 제고하여, 정책·규칙이 실제 행동으로 이어지도록 한다.

## 2. 수행 주체
- **주 수행자**: Cybersecurity Manager (CSM)
- **검토자**: Process Control Board (PCB)
- **승인자**: 경영진 (Top Management) — 역량·인식 프로그램 자원 승인

## 3. 범위
PRO-VCSMS-01-01 §5 단계 6 에 적용한다. 사이버보안 문화 조성([RQ-05-06]), 역할 담당자 역량·인식 보장([RQ-05-07])을 다룬다. **역량 관리 일반 메커니즘(직무역량 프레임워크·교육 행정)은 상위 §7.2 를 참조**하며, 본 지침은 사이버보안 특화 역량·인식만 다룬다(interface_only). 책임 배정은 선행 [[WI-VCSMS-01-01-02_책임_권한_배정_및_자원_제공]] 전제.

## 4. 입력 자료 / 산출물
- **Input**
  - 사이버보안 역할 정의·배정표([[WI-VCSMS-01-01-02_책임_권한_배정_및_자원_제공]] 산출물)
  - 역할별 요구 역량 프로파일(상위 §7.2 역량 프레임워크 참조)
  - ISO/SAE 21434 §5.4.2 [RQ-05-06·07] 요건
- **Output**
  - 역량·인식 관리대장 (WP-05-02)
  - 역량 격차 식별·보완 계획·이수 기록
  - 전사 사이버보안 인식 활동 기록(캠페인·교육)
  - [[TMP-VCSMS-01-01-03-01_역량_인식_관리대장]] 작성분

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. entry_gate 확인: WI-VCSMS-01-01-02 가 `done`(책임배정 완료) 인지 확인.
2. 사이버보안 역할별 요구 역량 프로파일 확보(상위 §7.2 역량 프레임워크에서 사이버보안 항목 추출).
3. 기존 교육·인식 활동 이력 수집.

### 5.2 수행 단계
1. **요구 역량 정의** ([RQ-05-07])
   - 역할별(CSM·보안 분석가·TARA 분석가·사고대응 등) 요구 역량 항목·수준 정의.
   - 각 역량 항목에 검증 방법(자격·이수·경험·평가) 지정.
2. **역량 평가·격차 식별**
   - 담당자별 현재 역량을 요구 수준과 대조하여 격차(gap) 식별.
   - [[TMP-VCSMS-01-01-03-01_역량_인식_관리대장]] 에 담당자·역량·요구/현재 수준·격차 기록.
3. **역량 보완 계획·이행**
   - 격차에 대한 보완 수단(교육·멘토링·외부 위탁·재배정) 결정·일정화.
   - 이수 결과를 관리대장에 갱신(이수일·평가 결과).
4. **문화·인식 활동** ([RQ-05-06])
   - 전사 사이버보안 인식 캠페인·정기 교육·사례 공유 계획·시행.
   - 경영진 메시지·정책 가시화로 문화 정착 신호 제공.
5. **충족률 점검·보고**
   - 사이버보안 역할 담당자 역량 충족률(KPI: 100% 목표) 산정.
   - 미충족 담당자에 대한 조치 상태와 함께 PCB·경영진에 반기 보고.
6. **등록**
   - 역량·인식 관리대장과 활동 기록을 MAT-001 에 등록·갱신.

### 5.3 완료 조건
- [ ] 사이버보안 역할별 요구 역량 항목·수준·검증 방법 정의 완료
- [ ] 담당자별 역량 격차 식별 및 관리대장 기록 완료
- [ ] 식별된 격차에 대한 보완 계획 수립·일정화
- [ ] 전사 인식 활동(캠페인/교육) 계획·시행 기록 확보
- [ ] 역량 충족률 산정(목표 100%) 및 미충족 조치 상태 명시
- [ ] PCB·경영진 반기 보고 및 MAT-001 등록 완료

## 6. 인터페이스 부서
- **HR/교육(§7.2)**: 역량 프레임워크·교육 행정 정본 — 본 지침은 사이버보안 항목만 참조
- **경영진**: 인식 프로그램 자원 승인·문화 메시지 발신
- **각 프로세스 소유 부서**: 담당자 역량 평가 협조

## 7. 주의사항 / 예외 처리

### 7.1 역량 격차 미해소 (보완 불가)
- 보완 기간 내 역량 격차가 해소되지 않는 경우:
  - 해당 담당자를 critical 활동에서 임시 배제하고 자격자에게 재배정.
  - 미해소 격차와 잔존 리스크를 PCB 에 보고.

### 7.2 상위 §7.2 와 중복
- 역량 관리 일반 프로세스가 상위 HR 시스템에 이미 존재하는 경우:
  - 본 지침은 사이버보안 특화 항목만 추가하고 일반 행정은 상위 시스템 "참조"(중복 생성 금지).

### 7.3 인식 활동 형식화 우려
- 인식 활동이 형식적 이수율 채우기에 그칠 우려가 있는 경우:
  - 사후 인식도 점검(설문·시뮬레이션 훈련)으로 실효성 검증.
  - 실효성 저조 시 콘텐츠·전달 방식 개선.
