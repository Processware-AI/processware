# 공격 타당성 평가 (등급표 적용) (WI-VCSMS-02-03-05)

> 상위 절차: [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]
> **횡단 방법론** — TARA 5단계. ISO §15.7 Table 1 원문 전재 금지 → 조직 자체 등급표 사용.

## 1. 업무 목적
각 공격 경로의 공격 타당성(attack feasibility) 등급을 조직 자체 등급표(공격잠재력/CVSS/공격벡터 중 채택 방법 기반)에 따라 결정하여, 리스크값 결정의 타당성 축을 제공한다. ISO §15.7 Table 1 원문은 직접 전재하지 않고 조직 등급표로 재구성하여 사용한다. (§15.7 [RQ-15-10~14])

## 2. 수행 주체
- **주 수행자**: TARA 분석가
- **검토자**: 보안 설계자
- **승인자**: TARA 분석가 (R/A — PRO §3 RACI)

## 3. 범위
본 지침은 PRO-VCSMS-02-03 §5 단계 5(공격 타당성)에 적용한다. 공격 경로(WI-04)를 입력으로 받아 공격 타당성 등급(WP-15-06)을 산출하며, 리스크값 결정(WI-VCSMS-02-03-06)의 입력이 된다. 타당성 방법은 공격잠재력 / CVSS / 공격벡터 중 조직이 정의한 하나를 일관 적용한다([RC-15-11]).

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-03-04-01_공격경로_분석서]] (승인, 경로 단계 포함)
  - 조직 자체 공격 타당성 등급표 (ISO Table 1 재구성, 채택 방법 정의)
- **Output**
  - [[TMP-VCSMS-02-03-05-01_공격타당성_평가표]] 작성분 (WP-15-06)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 공격 경로 분석서가 승인되었는지 확인한다(entry_gate).
2. 조직 등급표와 채택 방법(공격잠재력/CVSS/공격벡터)을 확인한다([RC-15-11]).

### 5.2 수행 단계
1. **방법별 지표 산정**
   - 공격잠재력 기반: 소요시간·전문성·지식·기회·장비 기준으로 지표를 산정한다([RC-15-12]).
   - CVSS 기반: 공격벡터·복잡도·권한·사용자 상호작용 등 이용성 지표를 산정한다([RC-15-13]).
   - 공격벡터 기반: 경로의 주된 공격벡터를 평가한다([RC-15-14]).
2. **타당성 등급 결정**
   - 산정 지표를 조직 등급표에 대입하여 경로별 공격 타당성 등급을 결정한다([RQ-15-10]).
3. **일관성 점검**
   - 동일 방법을 전 경로에 일관 적용했는지, 등급표 외 임의 판정이 없는지 점검한다.
4. **검토·승인**
   - 보안 설계자 검토 후 TARA 분석가가 평가표를 확정한다.

### 5.3 완료 조건
- [ ] 채택 방법(공격잠재력/CVSS/공격벡터) 일관 적용
- [ ] 경로별 지표 산정
- [ ] 조직 등급표로 타당성 등급 결정
- [ ] 등급표 외 임의 판정 0건 점검
- [ ] 평가표 확정(TARA 분석가 R/A)

## 6. 인터페이스 부서
- **보안 설계자**: 지표 산정 검토
- **펜테스트팀(해당 시)**: 실측 타당성 보정
- **품질(QMS)**: 산출물 형상·문서 관리 (§5.4.4 경계면)

## 7. 주의사항 / 예외 처리

### 7.1 등급표 외 임의 판정
- 조직 등급표 정의 외 임의 기준으로 등급을 매기려는 경우:
  - 금지(KPI: 자체 등급표 외 임의 판정 0건). 등급표 보완이 필요하면 등급표 개정 후 적용.

### 7.2 방법 혼용
- 일부 경로는 CVSS, 일부는 공격잠재력으로 혼용 평가한 경우:
  - 일관성 위반 — 단일 채택 방법으로 통일하여 재평가.

### 7.3 신규 취약점에 따른 타당성 변화
- 신규 취약점·공격 도구로 타당성이 상승한 경우:
  - 해당 경로 타당성을 재평가하고 리스크값(WI-06)을 갱신.
