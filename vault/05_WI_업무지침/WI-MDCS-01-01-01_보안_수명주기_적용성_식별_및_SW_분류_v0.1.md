# 보안 수명주기 적용성 식별 및 SW 항목 분류 (WI-MDCS-01-01-01)

> 상위 절차: [[PRO-MDCS-01-01_보안_거버넌스_및_일반요건_관리_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
헬스SW 제품(또는 그 일부)에 보안 수명주기 활동을 적용할 범위를 결정하고, 각 SW 항목을 보안 책임 수준에 따라 분류하여 후속 거버넌스·개발·유지보수·리스크 활동의 기준선을 확정한다. 분류 결과는 어떤 항목에 취약점 모니터링·보안 업데이트 의무가 적용되는지를 규정한다. (4.1.1, 4.1.3, 4.3)

## 2. 수행 주체
- **주 수행자**: 프로세스 오너
- **검토자**: 보안책임자(PSO)
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-01-01 §5 단계1~2(적용성 식별·SW 분류)에 적용한다. 본 지침은 제품 단위로 1회 수행하고 제품 구성 변경(신규 컴포넌트 추가·외부 SW 도입) 시 재수행한다. 역할 배정·역량은 WI-MDCS-01-01-02 가 담당한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 제품 목록·제품 구조 명세
  - SBOM(있는 경우) 또는 컴포넌트 인벤토리 초안
  - 제품의 의도된 사용·배포 형태 정보
- **Output**
  - [[TMP-MDCS-01-01-01-01_보안수명주기_적용성_및_SW분류표_v0.1]] 작성분
  - 적용성 판정 기록(적용 범위·제외 사유 포함)
  - SW 분류 결과(항목별 MAINTAINED/SUPPORTED/REQUIRED)

## 5. 수행 절차

### 5.1 사전 준비
1. 대상 제품의 구조 명세·컴포넌트 목록을 확보한다.
2. 제품의 의도된 사용 환경·배포 형태(제조자 통제 여부, 사용자 설치 가능성)를 파악한다.
3. 보안 수명주기 적용 판단 기준(POL-MDCS-01)을 확인한다.

### 5.2 수행 단계
1. **적용성 식별**
   - 제품 전체 또는 제품 일부 중 보안 수명주기 활동이 적용될 범위를 결정한다.
   - 제외 항목이 있으면 제외 사유(예: 보안 영향 없는 비실행 자산)를 문서화한다.
2. **SW 항목 분해**
   - 적용 범위 내 SW 를 항목 단위로 분해한다(자체 개발·외부 라이브러리·OTS·런타임).
3. **항목별 분류**
   - 각 SW 항목을 다음 기준으로 분류한다:
     - **MAINTAINED**: 제조자가 보안 업데이트를 직접 개발·제공하는 SW
     - **SUPPORTED**: 제조자가 취약점을 모니터링하나 업데이트는 제3자/사용자에 의존하는 SW
     - **REQUIRED**: 제품 동작에 필요하나 제조자 책임 밖인 사용자 환경 제공 SW
   - 분류 근거(누가 업데이트를 제공하는가)를 항목별로 기재한다.
4. **분류 결과 검토·승인**
   - PSO 가 분류 일관성·누락을 검토하고 승인한다.
   - 분류표를 거버넌스 산출물로 등록한다.

### 5.3 완료 조건
- [ ] 적용성 판정(적용 범위·제외 사유) 문서화 완료
- [ ] 적용 범위 내 모든 SW 항목이 분해되어 누락 없음
- [ ] 모든 SW 항목이 MAINTAINED/SUPPORTED/REQUIRED 중 하나로 분류됨(미분류 0건)
- [ ] 각 분류에 근거(업데이트 책임 주체) 기재
- [ ] PSO 검토·승인 기록 존재

## 6. 인터페이스 부서
- **형상관리 담당**: SBOM·컴포넌트 인벤토리 제공(PRO-MDCS-01-04 연계)
- **구매/공급자 관리**: 외부 SW 공급 형태 정보 제공
- **개발팀**: 제품 구조·런타임 의존성 정보 제공

## 7. 주의사항 / 예외 처리

### 7.1 분류 모호 항목
- MAINTAINED/SUPPORTED 경계가 불분명한 항목(예: 제조자가 부분적으로만 업데이트)은 **보수적으로 상위 책임(MAINTAINED)** 으로 분류하고 사유를 기재한다. 최종 판정은 PSO 가 한다.

### 7.2 외부 SW 추가·구성 변경
- 제품에 신규 외부 컴포넌트가 추가되면 본 지침을 재수행하여 분류표를 갱신하고, MAINTAINED 신규 항목은 PRO-MDCS-01-03(유지보수) 모니터링 대상에 즉시 반영한다.

### 7.3 적용 제외 항목의 사후 보안 영향 발견
- 제외 처리한 항목에서 보안 영향이 새로 식별되면 PRO-MDCS-01-05(문제해결)로 연계하고, 적용성 판정을 재검토한다.

### 7.4 분류 정보 부재
- 외부 컴포넌트의 업데이트 책임 주체가 불명확하면 구매/공급자 관리에 확인을 요청하고, 확인 전까지 SUPPORTED 로 잠정 분류한다(모니터링 누락 방지).
