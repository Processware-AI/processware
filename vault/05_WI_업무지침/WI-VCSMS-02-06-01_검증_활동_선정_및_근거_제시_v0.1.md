# 검증 활동 선정 및 근거 제시 (WI-VCSMS-02-06-01)

> 상위 절차: [[PRO-VCSMS-02-06_차량_수준_사이버보안_검증_절차]] · 상위 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
차량 수준 사이버보안 검증을 위해 적절한 검증 활동을 선정하고 그 선정 근거를 제시하여, 목표 적정성·달성·클레임·운용환경 요구의 유효성을 효과적으로 확인할 수 있도록 검증 계획의 정당성을 확보한다.

## 2. 수행 주체
- **주 수행자**: 검증 엔지니어
- **검토자**: Project CS Lead
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
ISO/SAE 21434 §11.4([RQ-11-02])에 적용한다. 본 지침은 검증 활동 선정과 근거 제시를 다룬다. 실제 검증 수행은 WI-06-02 가 담당한다. 입력은 제품개발([[PRO-VCSMS-02-05_제품개발_사이버보안_엔지니어링_절차]]) 산출물이다.

## 4. 입력 자료 / 산출물
- **Input**
  - 제품개발 산출물: 사양·통합·검증·테스트 결과([[PRO-VCSMS-02-05_제품개발_사이버보안_엔지니어링_절차]])
  - [[TMP-VCSMS-02-04-03-01_사이버보안_목표_클레임_명세서]] (검증 대상 목표·클레임)
  - [[TMP-VCSMS-02-04-01-01_아이템_정의서]] (운용환경 요구)
- **Output**
  - [[TMP-VCSMS-02-06-01-01_검증_활동_선정서]] 작성분

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 제품개발 산출물·목표·클레임·운용환경 요구를 검증 대상으로 정리한다.
2. 가용 검증 방법(시험·분석·시뮬레이션·차량 실증) 목록을 식별한다.
3. 선정서 양식([[TMP-VCSMS-02-06-01-01_검증_활동_선정서]])을 발번한다.

### 5.2 수행 단계
1. **검증 대상 정리**
   - 목표 적정성·달성, 클레임 유효성, 운용환경 요구 유효성을 검증 대상 항목으로 목록화한다.
2. **검증 활동 선정**
   - 각 검증 대상에 적합한 차량 수준 검증 활동을 선정한다.
3. **선정 근거 제시** ([RQ-11-02])
   - 각 선정 활동에 대해 선정 근거(대상 적합성·신뢰도·실현가능성·하위 검증과의 비중복)를 제시한다.
4. **검증 계획 구성**
   - 선정 활동의 범위·환경·일정·책임을 포함한 검증 계획을 구성한다.
5. **검토·승인**
   - Project CS Lead 검토를 반영하고 CSM 승인을 받는다.

### 5.3 완료 조건
- [ ] 검증 대상(목표·클레임·운용환경 요구) 목록화 완료
- [ ] 모든 검증 대상에 검증 활동 선정(미선정 0)
- [ ] 각 선정 활동에 근거 제시([RQ-11-02], 근거 없는 활동 0)
- [ ] 검증 계획(범위·환경·일정·책임) 구성
- [ ] CSM 승인 기록 확보

## 6. 인터페이스 부서
- **검증 엔지니어**: 선정 활동으로 검증 수행([[WI-VCSMS-02-06-02_차량_수준_사이버보안_검증_수행]])
- **제품개발팀**: 산출물·하위 검증 결과 제공

## 7. 주의사항 / 예외 처리

### 7.1 근거 없는 활동 배제
- 선정 근거를 제시할 수 없는 검증 활동은 계획에서 배제한다([RQ-11-02] 위반 방지). KPI: 근거 없는 검증 활동 0건.

### 7.2 하위 검증과 중복
- 제품개발(Clause 10) 하위 검증으로 이미 충분히 확인된 항목은 차량 수준에서 재검증 비중복 근거를 명시하고 활동을 최소화한다.

### 7.3 검증 불가 대상
- 차량 수준에서 검증 불가한 대상(예: 외부 인프라 의존 클레임)은 대체 검증(분석·공급자 합의) 또는 잔여 리스크 수용으로 표식하고 CSM 결정을 받는다.
