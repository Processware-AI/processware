# RFQ 발행 (사이버보안 요건 포함) (WI-VCSMS-02-08-02)

> 상위 절차: [[PRO-VCSMS-02-08_분산_사이버보안_활동_및_공급망_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
공급자에 발행하는 RFQ(견적 요청)에 사이버보안 요건을 명시적으로 포함하여, 공급자가 본 표준 준거 활동을 공식 약속하고 책임을 인수하도록 한다. RFQ 는 (a) 본 표준 준거 공식 요청, (b) 사이버보안 책임 인수 기대, (c) 관련 사이버보안 목표/요구 세 요소를 반드시 포함한다. (VCSMS-R-054 / [RQ-07-03])

## 2. 수행 주체
- **주 수행자**: 조달 담당
- **검토자**: Project CS Lead
- **승인자**: Cybersecurity Manager (CSM) — 사이버보안 요건 포함 승인

## 3. 범위
PRO-VCSMS-02-08 §5 단계 2(RFQ)에 적용한다. 선행 WI-VCSMS-02-08-01(역량 평가)이 적합/조건부로 완료된 후 착수한다(entry gate). RFQ 발행·견적·계약 일반 절차는 상위 조달(인터페이스 대상)을 따르고, 본 지침은 RFQ 의 사이버보안 요건 삽입·검증만 다룬다.

## 4. 입력 자료 / 산출물
- **Input**
  - 승인된 [[TMP-VCSMS-02-08-01-01_공급자_사이버보안_역량_평가표]] (적합/조건부 결과)
  - 공급 대상 활동의 사이버보안 목표·요구(컨셉/개발 단계 산출물)
  - 조달 표준 RFQ 양식
- **Output**
  - [[TMP-VCSMS-02-08-02-01_RFQ_사이버보안_요건_체크리스트]] 작성분
  - RFQ 에 삽입할 사이버보안 요건 부록(공식 요청·책임·목표/요구)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 역량 평가 결과에서 조건부 보완 요구가 있으면 이를 RFQ 요건에 포함하도록 준비한다.
2. 공급 대상 활동에 해당하는 사이버보안 목표·요구를 컨셉/개발 산출물에서 추출한다.
3. 조달과 RFQ 발행 일정·형식을 합의한다.

### 5.2 수행 단계
1. **공식 요청 문구 작성**
   - RFQ 에 "공급자는 ISO/SAE 21434 준거로 개발·사후개발 활동을 수행한다"는 공식 요청을 명시한다. (VCSMS-R-054 / [RQ-07-03])
2. **책임 인수 기대 명시**
   - 공급자가 인수할 사이버보안 책임 범위(활동·산출물·취약점 통지·인시던트 협조)의 기대를 명시한다.
3. **목표/요구 첨부**
   - 공급 대상에 적용되는 사이버보안 목표·요구를 RFQ 부록으로 첨부하고, 후속 CIA(WI-08-03)에서 책임 분배될 항목임을 안내한다.
4. **체크리스트 검증**
   - 사이버보안 요건 체크리스트로 3요소(공식요청·책임기대·목표요구) 누락을 점검한다.
5. **CSM 검토·승인 후 발행**
   - CSM 이 사이버보안 요건 충분성을 검토·승인한다.
   - 조달이 RFQ 를 발행하고 발행 사실·일자를 기록한다.

### 5.3 완료 조건
- [ ] RFQ 에 본 표준 준거 공식 요청 문구가 포함되었다
- [ ] 공급자 사이버보안 책임 인수 기대가 명시되었다
- [ ] 관련 사이버보안 목표·요구가 RFQ 에 첨부되었다
- [ ] 역량 평가의 조건부 보완 요구(있으면)가 RFQ 요건에 반영되었다
- [ ] 체크리스트로 3요소 누락 점검을 완료하고 CSM 승인을 받았다

## 6. 인터페이스 부서
- **조달/구매**: RFQ 발행·견적 접수·계약 진행
- **컨셉/개발팀**: 사이버보안 목표·요구 제공
- **CSM 조직**: 요건 충분성 검토

## 7. 주의사항 / 예외 처리

### 7.1 표준 RFQ 양식 미수정 가능
- 조달 표준 RFQ 양식 구조상 사이버보안 요건을 본문에 삽입할 수 없으면, 별첨(부록)으로 첨부하되 RFQ 본문에 "별첨 사이버보안 요건은 계약 구속력이 있다"는 명시 문구를 넣는다.

### 7.2 목표/요구 미확정 상태 RFQ
- 컨셉 단계가 진행 중이어서 사이버보안 목표/요구가 확정되지 않은 경우, 잠정 요구임을 명시하고 "확정 시 CIA 로 갱신·구속"한다는 조건부 문구를 포함한다. 확정 후 누락 없이 CIA(WI-08-03)에 반영한다.

### 7.3 다수 공급자 동시 RFQ
- 동일 활동을 다수 공급자에 RFQ 하는 경우, 사이버보안 요건 부록을 공통 표준화하여 공급자 간 요건 불일치를 방지하고, 비교 평가의 공정성을 확보한다.
