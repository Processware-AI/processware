# 공급자 사이버보안 역량 평가 (WI-VCSMS-02-08-01)

> 상위 절차: [[PRO-VCSMS-02-08_분산_사이버보안_활동_및_공급망_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
사이버보안 활동을 분산(외주)하기 전, 후보 공급자가 ISO/SAE 21434 준거의 개발·사후개발 활동을 수행할 역량이 있는지 평가한다. 평가 결과는 RFQ 발행·CIA 체결의 전제이며, 공급자가 제공한 역량 기록을 근거로 한다. (VCSMS-R-052 / [RQ-07-01], VCSMS-R-053 / [RC-07-02])

## 2. 수행 주체
- **주 수행자**: Project CS Lead
- **검토자**: 조달 담당
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
PRO-VCSMS-02-08 §5 단계 1(역량 평가)에 적용한다. 공급자 선정·재무·품질 일반 평가는 상위 공급자관리(§8.4, 인터페이스 대상)를 따르고, 본 지침은 사이버보안 수행 역량 측면만 평가한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 후보 공급자 목록·공급 대상 품목 범위
  - 공급자가 제공한 사이버보안 역량 기록(인증·프로세스·실적; VCSMS-R-053 권고)
  - 평가 기준(역량 영역·가중치·합격선)
- **Output**
  - [[TMP-VCSMS-02-08-01-01_공급자_사이버보안_역량_평가표]] 작성분
  - 평가 결과(적합/조건부/부적합)와 보완 요구(해당 시)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 공급 대상 활동의 사이버보안 위험 수준(높음/중간/낮음)을 분류하여 평가 강도를 정한다.
2. 공급자에게 사이버보안 역량 기록 제출을 요청한다(권고 사항이므로 미제출 시 §7.1 처리).
3. 평가 영역(프로세스·인력·도구·과거 실적·취약점 관리 역량)과 가중치·합격선을 확정한다.

### 5.2 수행 단계
1. **역량 기록 수령·확인**
   - 공급자 제출 기록의 진위·최신성을 확인한다. 미제출·부족 시 추가 요청한다. (VCSMS-R-053 / [RC-07-02])
2. **영역별 평가**
   - 평가 영역별로 점수를 부여하고 근거를 기재한다. (VCSMS-R-052 / [RQ-07-01])
     - 프로세스: 21434 준거 개발·사후개발 프로세스 보유
     - 인력: 사이버보안 역할·역량 보유
     - 도구·환경: 분석·검증 도구 운용
     - 실적: 유사 품목 양산 사이버보안 실적
     - 취약점 관리: 취약점 식별·조치·통지 역량([RQ-08-07] 연계)
3. **종합 판정**
   - 가중 합산 점수로 적합/조건부/부적합을 판정한다.
   - 조건부 시 보완 요구 항목·기한을 명시한다.
4. **CSM 검토·승인**
   - CSM 이 평가의 객관성·근거 충분성을 검토·승인한다.
5. **결과 통보·다음 단계 연계**
   - 적합/조건부 공급자는 RFQ(WI-08-02) 로 진행한다.
   - 부적합은 대안 공급자 탐색 또는 보완 후 재평가로 처리한다.

### 5.3 완료 조건
- [ ] 공급 대상 활동의 사이버보안 위험 수준이 분류되었다
- [ ] 공급자 역량 기록을 수령·확인했다(미제출 시 §7.1 처리 기록)
- [ ] 모든 평가 영역에 점수·근거가 기재되었다
- [ ] 종합 판정(적합/조건부/부적합)과 보완 요구가 명시되었다
- [ ] CSM 검토·승인이 완료되었다

## 6. 인터페이스 부서
- **조달/구매**: 공급자 목록·계약 일반 평가 연계
- **공급자관리(§8.4)**: 재무·품질 평가 결과 공유
- **CSM 조직**: 평가 기준·객관성 검토

## 7. 주의사항 / 예외 처리

### 7.1 역량 기록 미제출(권고 미이행)
- 역량 기록 제출은 권고(should)이므로 미제출만으로 즉시 부적합 처리하지 않는다. 대체 증빙(질의 응답·현장 실사·서약)을 요청하고, 끝내 검증 불가 시 위험을 명시한 조건부 판정 또는 부적합으로 처리한다.

### 7.2 평가 결과와 조달 결정 충돌
- 사이버보안 평가는 부적합이나 조달·원가 사유로 선정이 불가피한 경우, 임의 진행하지 않고 CSM·Project CS Lead·조달이 위험 수용 여부를 공동 결정하고, 보완 통제(추가 CIA 책임·집중 감사)를 CIA(WI-08-03)에 반영한다.

### 7.3 기존 거래 공급자
- 기존 거래 공급자라도 신규 사이버보안 활동 분산 시 본 평가를 생략하지 않는다. 단, 유효한 최근 평가가 있으면 차이(델타) 평가로 갈음하고 그 근거를 기록한다.
