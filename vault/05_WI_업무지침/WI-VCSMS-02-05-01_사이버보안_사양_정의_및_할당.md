# 사이버보안 사양 정의 및 컴포넌트 할당 (WI-VCSMS-02-05-01)

> 상위 절차: [[PRO-VCSMS-02-05_제품개발_사이버보안_엔지니어링_절차]] · 상위 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
컨셉 단계의 사이버보안 요구·통제와 기존 설계를 기반으로 구체적인 사이버보안 사양을 정의하고, 이를 아키텍처 컴포넌트에 할당하며, (해당 시)개발 후 사이버보안 보장 절차를 명시하여 설계·구현의 기준을 확정한다.

## 2. 수행 주체
- **주 수행자**: 보안 설계자
- **검토자**: Project CS Lead, 개발자
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
ISO/SAE 21434 §10.4.1([RQ-10-01], [RQ-10-02], [RQ-10-03])에 적용한다. 입력은 컨셉([[PRO-VCSMS-02-04_컨셉_단계_사이버보안_엔지니어링_절차]])의 요구·통제다. 사양 검증은 후속 WI-05-04 가 담당한다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-04-05-01_사이버보안_컨셉_및_요구사항_명세서]] (전달 산출물, WP-09-06)
  - 기존 설계·아키텍처 자산, 선정 통제 목록
- **Output**
  - [[TMP-VCSMS-02-05-01-01_사이버보안_사양서]] 작성분 (WP-10-01, 부속 WP-10-02 개발후 요구)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 컨셉 검증 통과 산출물(WP-09-06)을 수령·검토한다.
2. 기존 설계·재사용 컴포넌트 목록과 선정 통제를 정렬한다.
3. 사양서 양식([[TMP-VCSMS-02-05-01-01_사이버보안_사양서]])을 발번한다.

### 5.2 수행 단계
1. **사이버보안 사양 정의** ([RQ-10-01])
   - 상위 추상화 사양(컨셉 요구)·선정 통제·기존 설계를 기반으로 구체 사양(SP-##)을 정의한다.
   - 각 사양을 검증 가능한 형태(입력·동작·기준)로 기술한다.
2. **컴포넌트 할당** ([RQ-10-02])
   - 정의된 사이버보안 요구·사양을 아키텍처 컴포넌트에 할당한다.
   - 다중 컴포넌트 분담 시 인터페이스 책임을 명시한다.
3. **개발 후 보장 절차 명시** ([RQ-10-03])
   - 개발 후 사이버보안 보장이 필요한 사양에 대해 절차(운영·유지·업데이트 요구)를 (해당 시) 명시한다(WP-10-02 연계).
4. **추적성 연결**
   - 컨셉 요구(CR-##)→사양(SP-##)→컴포넌트 할당의 추적을 연결한다.
5. **검토·승인**
   - Project CS Lead·개발자 검토를 반영하고 CSM 승인을 받는다.

### 5.3 완료 조건
- [ ] 컨셉 요구(CR-##) 전건이 사양(SP-##)으로 구체화(누락 0)
- [ ] 모든 사양이 컴포넌트에 할당(미할당 0)
- [ ] (해당 시)개발 후 보장 절차 명시
- [ ] CR↔SP↔컴포넌트 추적 연결 확인
- [ ] CSM 승인 기록 확보

## 6. 인터페이스 부서
- **개발자**: 사양 기반 설계·구현 착수([[WI-VCSMS-02-05-02_설계_구현_원칙_및_언어_코딩_기준_적용]])
- **보안 설계자**: 아키텍처 약점 분석 착수([[WI-VCSMS-02-05-03_아키텍처_약점_분석]])
- **운영팀**: 개발 후 보장 절차 인수

## 7. 주의사항 / 예외 처리

### 7.1 컨셉 요구 모호
- 컨셉 요구가 사양화하기에 모호하면, 임의 해석 금지. 컨셉 단계([[PRO-VCSMS-02-04_컨셉_단계_사이버보안_엔지니어링_절차]])로 명확화 요청 후 사양을 정의한다.

### 7.2 재사용 컴포넌트 사양 격차
- 재사용 컴포넌트가 사양을 부분 충족하면, 격차(gap)를 식별하고 보완 사양 또는 추가 통제를 정의한다([[PRO-VCSMS-02-01_프로젝트_사이버보안_관리_절차]] 재사용 분석 연계).

### 7.3 컴포넌트 미확정
- 아키텍처 컴포넌트가 미확정이면, 할당을 "잠정(TBD)"으로 표기하고 확정 시 사양서를 개정한다.
