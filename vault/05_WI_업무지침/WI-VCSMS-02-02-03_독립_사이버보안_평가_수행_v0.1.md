# 독립 사이버보안 평가 수행 (WI-VCSMS-02-02-03)

> 상위 절차: [[PRO-VCSMS-02-02_사이버보안_케이스_평가_및_릴리스_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
독립 Assessor 가 사이버보안 케이스와 그 증적을 기반으로 계획·작업산출물·리스크 처리·통제의 적정성과 근거를 평가하여, item/component 의 사이버보안 달성 여부를 독립적으로 판정한다. (§6.4.8 [RQ-06-26,28,30])

## 2. 수행 주체
- **주 수행자**: Assessor(독립)
- **검토자**: Cybersecurity Manager (CSM) — 협조·정보 제공 보장
- **승인자**: Assessor(독립) — 평가 결과의 독립적 판정 권한

## 3. 범위
본 지침은 PRO-VCSMS-02-02 §5 단계 4(독립 평가)에 적용한다. mandatory=false(평가 수행 결정 시에만). 평가 범위는 계획·WP·리스크 처리·통제 적정성·근거를 포함한다([RQ-06-30]). 평가 결과의 보고서화는 WI-VCSMS-02-02-04 로 이어진다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-02-01-01_사이버보안_케이스]] (승인) 및 증적 WP
  - [[TMP-VCSMS-02-02-02-01_평가수행_결정서]] (평가 범위)
  - 관련 정보·도구·인력 접근 보장 ([RQ-06-28])
- **Output**
  - [[TMP-VCSMS-02-02-03-01_독립평가_체크리스트]] 작성분 (항목별 평가 결과·발견사항)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 평가 수행 결정서에서 평가 범위·대상을 확인한다(entry_gate).
2. CSM 에게 관련 정보·도구·인력 협조 접근을 요청·확보한다([RQ-06-28]).
3. 평가 체크리스트(계획·WP·리스크 처리·통제·근거 항목)를 준비한다.

### 5.2 수행 단계
1. **계획·WP 적정성 평가**
   - 사이버보안 계획과 작업산출물이 표준 요구를 충족하는지 평가한다([RQ-06-30]).
   - 작업산출물 정확성·갱신 유지를 확인한다([RQ-06-26]).
2. **리스크 처리·통제 평가**
   - TARA 리스크 처리 결정과 통제의 적정성, 잔여 리스크 정당화를 평가한다.
3. **근거 평가**
   - 케이스 논거가 증적으로 합리적으로 뒷받침되는지 평가한다.
4. **발견사항 정리**
   - 항목별 결과(적합/조건부/부적합)와 발견사항·근거를 체크리스트에 기록한다.
   - 평가 근거를 본 표준 목적 달성 판단에 활용할 수 있다([PM-06-29]).

### 5.3 완료 조건
- [ ] 정보·도구·인력 접근 확보
- [ ] 계획·WP 적정성 및 정확성·갱신 평가
- [ ] 리스크 처리·통제 적정성 및 잔여 리스크 정당화 평가
- [ ] 케이스 근거(논거↔증적) 평가
- [ ] 항목별 결과·발견사항·근거 기록

## 6. 인터페이스 부서
- **CSM/프로젝트팀**: 정보·도구·인력 협조 ([RQ-06-28])
- **TARA 분석가**: 리스크 처리 근거 설명
- **검증팀**: 검증 증적 설명

## 7. 주의사항 / 예외 처리

### 7.1 접근 비협조
- 평가에 필요한 정보·도구·인력 접근이 제공되지 않는 경우:
  - CSM 에 즉시 에스컬레이션하고, 미해소 시 해당 항목을 "평가 불가"로 기록.
  - 평가 불가 항목은 거부/조건부 권고 사유가 됨.

### 7.2 평가 중 중대 결함 발견
- 평가 중 릴리스를 막는 중대 결함(미처리 고위험 등)이 발견된 경우:
  - 즉시 CSM·프로젝트팀에 통보하고 보완 후 재평가 경로로 전환.
  - 보고서 작성(WI-04)에서 거부 권고로 연결.

### 7.3 독립성 훼손 정황
- 평가 과정에서 Assessor 독립성이 훼손될 정황(압력·이해상충)이 발생한 경우:
  - 평가를 중단하고 거버넌스(독립 감사 PRO-VCSMS-01-02)에 보고.
