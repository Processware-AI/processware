# TARA 수행 호출 및 처리 옵션 결정 (WI-VCSMS-02-04-02)

> 상위 절차: [[PRO-VCSMS-02-04_컨셉_단계_사이버보안_엔지니어링_절차]] · 상위 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
확정된 아이템 정의를 입력으로 TARA([[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]]) 전(全) 단계(§15.3~15.8)를 호출·수령하고, 각 위협 시나리오에 대해 리스크 처리 옵션(회피·감소·공유·보유)을 §15.9 기준으로 결정하여, 목표·클레임 도출의 근거를 확보한다.

## 2. 수행 주체
- **주 수행자**: TARA 분석가
- **검토자**: Project CS Lead, 보안 설계자
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
ISO/SAE 21434 §9.4([RQ-09-03], [RQ-09-04])에 적용한다. TARA 방법론 자체는 [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]]가 수행하며, 본 지침은 컨셉 단계에서 TARA 를 호출(입력 전달·결과 수령)하고 처리 옵션을 결정하는 인터페이스를 다룬다. 리스크값 1 위협 시나리오는 [PM-06-08] 허용에 따라 후속 적합성을 생략할 수 있다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-04-01-01_아이템_정의서]] 확정본 (WP-09-01)
  - TARA 결과: 위협 시나리오·리스크값(WP-15-03,07,08, [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]] 산출)
- **Output**
  - [[TMP-VCSMS-02-04-02-01_리스크_처리_결정서]] 작성분 (WP-09-02 연계)
  - 위협 시나리오별 처리 옵션 결정 기록

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 아이템 정의서가 CSM 승인 완료(WI-04-01) 상태인지 확인한다(entry_gate).
2. TARA 절차에 아이템 정의서를 입력으로 전달하고 수행을 의뢰한다.
3. 리스크 처리 결정서 양식([[TMP-VCSMS-02-04-02-01_리스크_처리_결정서]])을 발번한다.

### 5.2 수행 단계
1. **TARA 결과 수령** ([RQ-09-03])
   - TARA 절차로부터 위협 시나리오·공격경로·공격타당성·리스크값(1~5)을 수령한다.
   - 아이템 정의의 모든 자산·피해 시나리오가 분석에 반영되었는지 커버리지를 확인한다.
2. **리스크값 트리아지**
   - 리스크값 1 위협 시나리오를 식별하고, [PM-06-08] 적용 여부와 생략 근거를 기록한다(생략 시 §9.5·Clause 10·11 적합성 면제).
3. **처리 옵션 결정** ([RQ-09-04], §15.9)
   - 각 위협 시나리오에 회피·감소·공유·보유 중 하나(또는 조합)를 결정한다.
   - 결정 근거(리스크값·수용가능성·비용·기술 타당성)를 기재한다.
4. **목표/클레임 분기 표식**
   - 감소 → 후속 "사이버보안 목표" 도출 대상으로 표식한다.
   - 공유/(가정기반)보유 → 후속 "사이버보안 클레임" 도출 대상으로 표식한다([[WI-VCSMS-02-04-03_사이버보안_목표_클레임_도출]] 입력).
5. **검토·승인**
   - Project CS Lead·보안 설계자 검토 의견을 반영한다.
   - CSM 승인을 받고 결정서를 확정한다.

### 5.3 완료 조건
- [ ] entry_gate(WI-04-01 done) 충족 확인
- [ ] TARA 결과 수령 및 자산·피해 시나리오 커버리지 확인
- [ ] 모든 위협 시나리오에 처리 옵션 1건 이상 결정(누락 0)
- [ ] 리스크값 1 생략 적용 시 근거 기록
- [ ] 감소→목표 / 공유·보유→클레임 분기 표식 완료
- [ ] CSM 승인 기록 확보

## 6. 인터페이스 부서
- **TARA 분석가/팀**: [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]] 수행·결과 제공
- **Project CS Lead**: 후속 목표·클레임 도출 인수
- **CSM**: 처리 옵션 결정 승인

## 7. 주의사항 / 예외 처리

### 7.1 TARA 커버리지 미달
- 아이템 정의의 일부 자산·피해 시나리오가 TARA 에 누락되면, 처리 옵션을 결정하지 말고 TARA 절차로 반려하여 재분석을 의뢰한다.

### 7.2 리스크값 1 생략 남용 방지
- 리스크값 1 생략([PM-06-08])은 §15.8 분석 완료를 전제로만 적용한다. 분석 미완 상태의 추정 생략은 금지하며, 생략 근거를 결정서에 명시한다.

### 7.3 처리 옵션 충돌 (감소+보유 혼재)
- 동일 위협에 감소와 보유가 혼재하면, 잔여 리스크 부분만 보유로 분리하고 감소 대상 부분에 목표를 부여한다. 분리 기준을 CSM 이 확정한다.
