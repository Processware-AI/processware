# 생산 통제 계획 이행 (WI-VCSMS-02-07-03)

> 상위 절차: [[PRO-VCSMS-02-07_생산_사이버보안_통제_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
승인된 생산 통제 계획과 무단 변경 방지 통제를 양산 현장에 적용하고, 각 산출물이 사이버보안 요구를 충족함을 확인·기록한다. 미충족 발견 시 시정하고 재이행하여 양산 산출물의 사이버보안 적합성을 보증한다. (VCSMS-R-096 / [RQ-12-03])

## 2. 수행 주체
- **주 수행자**: 생산 라인 담당자(작업·검사)
- **검토자**: 생산기술 담당자
- **승인자**: Cybersecurity Manager (CSM) — 정기 이행 점검 승인

## 3. 범위
PRO-VCSMS-02-07 §5 단계 3(이행)에 적용한다. 선행 WI-VCSMS-02-07-02(통제 정의)가 승인(done)된 후 양산 개시와 함께 운영한다(entry gate). 일반 생산 작업·품질검사 운영은 상위 QMS(인터페이스 대상)를 따르며, 본 지침은 사이버보안 통제의 이행·확인·기록만 다룬다.

## 4. 입력 자료 / 산출물

  - 양산 작업 지시·MES 작업 데이터

  - 미충족 시 시정 조치·재이행 기록

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 양산 개시 전, 계획서의 통제 항목과 통제 정의서의 통제 ID 가 라인 작업 지시에 반영되었는지 확인한다.
2. 통제에 필요한 도구·설비(서명기·검증 지그)의 가용·교정 상태를 점검한다.
3. 이행 기록부의 확인 항목·합격기준을 작업자·검사자가 숙지했는지 확인한다.

### 5.2 수행 단계
1. **통제 적용**
   - 양산 각 단계에서 계획·통제 정의에 따라 사이버보안 통제를 적용한다(키 주입·락 설정·봉인 등).
2. **요구 충족 확인**
   - 각 산출물(또는 표본)에 대해 계획서의 (d) 확인법으로 요구 충족 여부를 확인한다. (VCSMS-R-096 / [RQ-12-03])
   - 확인 결과(Pass/Fail)·측정값·시각을 이행 기록부에 기록한다.
3. **무단 변경 통제 점검**
   - 통제 유효성 확인 방법(주기 점검·로그 감사)을 정의된 주기로 수행하고 결과를 기록한다.
4. **미충족 처리**
   - Fail 발생 시 해당 산출물을 격리하고 시정 조치(재작업·재주입)를 수행한 뒤 재확인한다.
   - 동일 항목 반복 Fail 시 생산기술에 통보하고, 원인이 계획·통제 결함이면 선행 WI 로 피드백한다.
5. **정기 이행 점검·승인**
   - 생산기술이 일/주 단위로 이행 기록을 검토한다.
   - CSM 이 정기(예: 월) 이행 점검 결과를 검토·승인하고 KPI(요구 충족율·무단변경 0건)를 확인한다.

### 5.3 완료 조건
- [ ] 계획·통제 정의가 라인 작업 지시에 반영되었음을 확인했다
- [ ] 모든 산출물(또는 정의된 표본)에 대해 요구 충족 확인 결과가 기록되었다
- [ ] 통제 유효성 점검이 정의된 주기대로 수행·기록되었다
- [ ] 미충족(Fail) 건은 격리·시정·재확인이 완료되었다
- [ ] 생산기술 검토 및 CSM 정기 이행 점검 승인이 완료되었다

## 6. 인터페이스 부서
- **품질보증/QMS**: 검사 운영·부적합 처리 연계
- **MES 운영**: 이행·확인 데이터 기록 인프라
- **CSM 조직**: 정기 이행 점검·KPI 검토

## 7. 주의사항 / 예외 처리

### 7.1 반복 미충족(체계적 결함)
- 동일 통제 항목에서 Fail 이 반복되면 우발이 아닌 체계적 결함으로 보고, 양산을 일시 보류한 뒤 PRO-VCSMS-02-07 §5 단계 1~2(계획·통제 재정의)로 에스컬레이션한다.

### 7.2 통제 도구 고장
- 양산 중 통제 도구가 고장 나면 해당 라인을 정지한다. 대체 통제(수동 검증)로 임시 운영할 경우 그 한계를 기록하고 CSM 의 임시 운영 승인을 받는다. 고장 기간 산출물은 전수 재검사한다.

### 7.3 무단 변경 탐지
- 이행 중 무단 변경(통제 우회·위변조)이 탐지되면 즉시 라인을 정지하고 영향 산출물을 격리한다. NCR 을 발행하고, CSM 이 PRO-VCSMS-01-04(사고 대응) 연계 여부를 판정한다.
