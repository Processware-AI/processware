# 사이버보안 활동 테일러링 및 근거 검토 (WI-VCSMS-02-01-04)

> 상위 절차: [[PRO-VCSMS-02-01_프로젝트_사이버보안_관리_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
사이버보안 활동을 프로젝트 맥락에 맞게 테일러링(축소·생략·병합)할 때, 그 적정성·충분성에 대한 근거를 제시하고 독립 검토(PCB)를 거쳐 승인함으로써, 근거 없는 활동 누락을 방지한다. (§6.4.3 [PM-06-13] 허용, [RQ-06-14] 근거 의무)

## 2. 수행 주체
- **주 수행자**: Project CS Lead
- **검토자**: TARA 분석가 / CSM
- **승인자**: Process Control Board (PCB)

## 3. 범위
본 지침은 PRO-VCSMS-02-01 §5 단계 4(테일러링)에 적용한다. mandatory=false(선택 단계)이나, 테일러링을 적용하려면 본 지침을 반드시 거친다. 대표 사례로 §15.8 리스크값 1 위협 시나리오의 §9.5·Clause 10·11 적합성 생략([PM-06-08])이 있다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-01-03-01_사이버보안_계획서]] (승인)
  - 테일러링 후보 목록 (관련성 판정서 §3)
  - TARA 결과(리스크값) — 생략 근거 판단용
- **Output**
  - [[TMP-VCSMS-02-01-04-01_테일러링_근거서]] 작성분 (활동·근거·검토 결과)
  - 갱신된 사이버보안 계획 (테일러링 반영)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 계획서가 승인되었는지 확인한다(entry_gate).
2. 테일러링 후보 활동과 관련 근거 자료(리스크값·재사용 이력)를 수집한다.

### 5.2 수행 단계
1. **테일러링 대상·유형 식별**
   - 각 후보 활동에 대해 테일러링 유형(생략/축소/병합/대체)을 명시한다([PM-06-13]).
2. **근거 작성**
   - 적정성(왜 적절한가)·충분성(잔여 리스크가 허용 가능한가) 근거를 작성한다([RQ-06-14]).
   - 리스크값 1 기반 생략은 TARA 산출물(WP-15-07)을 근거로 인용한다([PM-06-08]).
3. **독립 검토**
   - PCB 가 근거의 타당성을 독립적으로 검토하고 승인/조건부/반려를 결정한다.
4. **계획 반영**
   - 승인된 테일러링을 사이버보안 계획에 반영하고 변경 이력을 남긴다.
   - 반려 시 해당 활동을 표준대로 수행하도록 계획을 환원한다.

### 5.3 완료 조건
- [ ] 테일러링 대상·유형 명시
- [ ] 적정성·충분성 근거 작성(잔여 리스크 평가 포함)
- [ ] 리스크값 1 생략 시 TARA 근거 인용
- [ ] PCB 독립 검토·승인
- [ ] 승인 결과(승인/반려)를 계획에 반영

## 6. 인터페이스 부서
- **PCB**: 테일러링 근거 독립 검토·승인
- **품질(QMS)**: 근거서 형상·문서 관리 (§5.4.4 경계면)

## 7. 주의사항 / 예외 처리

### 7.1 근거 불충분 (반려)
- PCB 가 근거를 불충분으로 판단 시:
  - 테일러링을 적용하지 않고 활동을 표준대로 수행하도록 계획 환원.
  - 보완 근거 확보 후 재신청 가능.

### 7.2 사후 리스크 변화
- 테일러링 후 TARA 재수행으로 리스크값이 상승한 경우:
  - 해당 테일러링을 즉시 무효화하고 생략 활동을 복원.
  - 계획 갱신(WI-06)으로 반영하고 PCB 재보고.

### 7.3 안전 연계 활동 테일러링 제한
- 안전(ISO 26262 연계) 영향이 있는 활동의 테일러링은:
  - 기능안전팀 동의를 필수 조건으로 하고, 동의 없으면 테일러링 불가.
