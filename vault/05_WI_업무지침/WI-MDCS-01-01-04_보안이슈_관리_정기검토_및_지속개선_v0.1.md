# 보안 이슈 관리 프로세스 정기 검토 및 지속개선 (WI-MDCS-01-01-04)

> 상위 절차: [[PRO-MDCS-01-01_보안_거버넌스_및_일반요건_관리_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
보안 이슈 관리 프로세스를 정기적으로(연 1회 이상 또는 QMS 모니터링의 일부로) 검토하여 효과성을 확인하고, 현장 결함 분석을 포함한 개선 활동을 통해 보안 수명주기를 지속적으로 향상한다. (4.1.6, 4.1.8)

## 2. 수행 주체
- **주 수행자**: 보안책임자(PSO)
- **검토자**: 보안운영위원회(PSGB)
- **승인자**: 보안운영위원회(PSGB)

## 3. 범위
PRO-MDCS-01-01 §5 단계6~7(지속개선·정기 검토)에 적용한다. 연 1회 이상 정기 수행하며, 중대 보안 사건 발생 시 임시 검토를 추가한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 보안 이슈·취약점 처리 현황(PRO-MDCS-01-05 산출)
  - 현장 결함·불만·필드 사고 보고
  - 이전 검토 결과·개선 조치 진행 상황
  - 관련 KPI(통제점) 실적
- **Output**
  - [[TMP-MDCS-01-01-04-01_보안프로세스_정기검토_및_개선보고서_v0.1]] 작성분
  - 검토 보고서(검토 일자·결론·개선 항목)
  - 개선 조치 계획·추적 항목

## 5. 수행 절차

### 5.1 사전 준비
1. 검토 기준 기간의 보안 이슈·취약점 처리 데이터를 집계한다.
2. 현장 결함·필드 사고·불만을 분석 가능한 형태로 정리한다.
3. 이전 검토의 개선 조치 이행 여부를 확인한다.

### 5.2 수행 단계
1. **효과성 평가**
   - 보안 이슈 관리 프로세스의 KPI 달성·SLA 준수·재발 여부를 평가한다.
2. **현장 결함 분석**
   - 필드에서 보고된 결함·사고의 근본 원인을 분석하고 프로세스 시사점을 도출한다.
3. **개선 항목 도출**
   - 효과성·결함 분석 결과로부터 개선 항목을 도출하고 우선순위를 정한다.
4. **개선 조치 계획**
   - 개선 항목별 담당·기한·완료 기준을 정한다.
5. **검토 보고·승인**
   - 검토 결과·개선 계획을 PSGB 에 보고하고 승인받는다(검토 일자 기록).
6. **개선 추적**
   - 승인된 개선 조치의 이행을 추적하고 다음 검토에서 종결 여부를 확인한다.

### 5.3 완료 조건
- [ ] 검토 기준 기간 데이터가 집계됨
- [ ] 프로세스 효과성 평가 수행
- [ ] 현장 결함 근본 원인 분석 수행
- [ ] 개선 항목 도출·우선순위·담당·기한 지정
- [ ] 검토 일자가 명시된 검토 보고서 작성
- [ ] PSGB 검토·승인 기록 존재
- [ ] 이전 검토 개선 조치 이행 여부 확인

## 6. 인터페이스 부서
- **품질경영(QMS)**: QMS 모니터링·경영검토와의 연계
- **PRO-MDCS-01-05(문제해결)**: 이슈 처리 데이터 제공
- **고객지원/CS**: 현장 결함·불만 정보 제공

## 7. 주의사항 / 예외 처리

### 7.1 검토 주기 미준수 우려
- 연 1회 검토 기한이 임박했으나 데이터가 미비하면 가용 데이터로 검토를 수행하되 데이터 한계를 보고서에 명시하고 보완 일정을 잡는다(검토 자체를 연기하지 않는다).

### 7.2 중대 보안 사건 발생
- 중대 보안 사건·반복 취약점이 발생하면 정기 주기와 무관하게 임시 검토를 즉시 실시하고, 결과를 다음 정기 검토에 통합한다.

### 7.3 개선 조치 지연
- 개선 조치가 기한 내 미완료되면 사유·재계획을 PSGB 에 보고하고, 보안 리스크가 있는 항목은 PRO-MDCS-02-01 로 리스크를 반영한다.

### 7.4 KPI 미설정 영역
- 정량 KPI 가 없는 영역은 정성 평가(사례 검토·인터뷰)로 대체하고, 차기 사이클에 KPI 신설을 개선 항목으로 등록한다.
