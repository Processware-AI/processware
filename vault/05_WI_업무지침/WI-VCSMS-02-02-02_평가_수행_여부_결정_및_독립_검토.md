# 평가 수행 여부 결정 및 독립 검토 (WI-VCSMS-02-02-02)

> 상위 절차: [[PRO-VCSMS-02-02_사이버보안_케이스_평가_및_릴리스_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
사이버보안 케이스의 리스크 수준을 근거로 독립 사이버보안 평가 수행 여부를 결정하고, 그 결정 근거가 합리적인지 독립적으로 검토함으로써, 평가 자원을 리스크에 비례하게 배분한다. (§6.4.8 [RQ-06-24,25])

## 2. 수행 주체
- **주 수행자**: Cybersecurity Manager (CSM)
- **검토자**: Assessor(독립) — 결정 근거 독립 검토
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
본 지침은 PRO-VCSMS-02-02 §5 단계 2(평가 결정)·단계 3(독립 검토)에 적용한다. 평가 수행으로 결정되면 WI-VCSMS-02-02-03 으로 이어지고, 미수행으로 결정되면 릴리스 준비(WI-05)로 직행하되 결정 근거를 보존한다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-02-01-01_사이버보안_케이스]] (승인)
  - TARA 리스크값 분포 (WP-15-07)
  - 평가 책임자 지정(§6.4.8 [RQ-06-27])
- **Output**
  - [[TMP-VCSMS-02-02-02-01_평가수행_결정서]] 작성분 (결정·근거·독립 검토 의견)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 케이스가 승인되었는지 확인한다(entry_gate).
2. TARA 리스크값 분포와 보유·공유 리스크 정당화 수준을 확인한다.

### 5.2 수행 단계
1. **리스크 기반 결정**
   - 최고 리스크값·잔여 리스크·신규성·안전 연계 여부를 기준으로 독립 평가 수행 여부를 결정한다([RQ-06-24]).
   - 결정 기준(예: 리스크값 ≥ 임계, 안전 연계 시 필수)을 명시한다.
2. **평가 책임자 지정 (수행 시)**
   - 평가 수행으로 결정 시 독립 평가를 계획·수행할 책임자(Assessor)를 지정한다([RQ-06-27]).
3. **독립 검토**
   - Assessor 가 결정 근거를 독립적으로 검토하고 동의/이의 의견을 제시한다([RQ-06-25]).
   - 이의 시 CSM 과 재협의하여 결정을 조정한다.
4. **결정 확정·기록**
   - 최종 결정(수행/미수행)과 근거·독립 검토 의견을 결정서에 기록하고 CSM 승인한다.

### 5.3 완료 조건
- [ ] 리스크 기반 결정 기준 명시
- [ ] 평가 수행/미수행 결정
- [ ] (수행 시) 독립 평가 책임자 지정
- [ ] Assessor 의 결정 근거 독립 검토 완료
- [ ] 결정·근거·검토 의견 기록 + CSM 승인

## 6. 인터페이스 부서
- **품질본부/독립조직**: Assessor 제공·독립성 보장
- **TARA 분석가**: 리스크값 근거 제공
- **기능안전팀**: 안전 연계 시 평가 필요성 의견

## 7. 주의사항 / 예외 처리

### 7.1 독립성 충돌
- 지정된 Assessor 가 본 프로젝트 개발에 관여한 경우:
  - 이해상충으로 간주하고 다른 독립 Assessor 로 교체.
  - 사내 인력 부재 시 외부 평가기관 활용.

### 7.2 결정 근거 이의
- Assessor 가 미수행 결정에 이의를 제기한 경우:
  - 보수적으로 평가 수행 쪽으로 조정하거나 추가 근거를 보강.
  - 이의·조정 과정을 결정서에 기록.

### 7.3 안전 연계 항목 미수행 시도
- 안전(ISO 26262 연계) 영향이 있는 item 의 평가를 미수행하려는 경우:
  - 기능안전팀 동의 없이는 미수행 불가.
  - 안전 연계 시 평가 수행을 기본값으로 한다.
