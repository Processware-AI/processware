# 생산 통제 계획 작성 (WI-VCSMS-02-07-01)

> 상위 절차: [[PRO-VCSMS-02-07_생산_사이버보안_통제_절차]] · 기준: [[표준프로세스_구성원칙]]

## 1. 업무 목적
릴리스 단계에서 인계된 post-development 사이버보안 요구를 양산 공정에 반영하기 위한 **생산 통제 계획**을 작성한다. 본 계획은 양산 산출물이 사이버보안 요구를 충족하고 의도하지 않은 변경 없이 생산되도록 하는 통제 기준선이다. (VCSMS-R-094, R-095 / [RQ-12-01], [RQ-12-02])

## 2. 수행 주체
- **주 수행자**: 생산기술 담당자
- **검토자**: Cybersecurity Manager (CSM)
- **승인자**: Project CS Lead

## 3. 범위
PRO-VCSMS-02-07 §5 단계 1(계획 작성)에 적용한다. 생산 공정 일반·작업표준서 운영은 상위 QMS/생산관리(인터페이스 대상)를 참조하며, 본 지침은 사이버보안 측면의 통제 항목 작성만 다룬다.

## 4. 입력 자료 / 산출물
- **Input**
  - 릴리스에서 인계된 post-development 사이버보안 요구 ([[PRO-VCSMS-02-02_사이버보안_케이스_평가_및_릴리스_절차]] 출력, VCSMS-R-050/051)
  - 대상 품목·부품의 양산 BOM·공정 흐름(QMS 제공)
  - 적용 가능한 도구·설비·검증 수단 목록
- **Output**
  - [[TMP-VCSMS-02-07-01-01_생산_통제_계획서]] 작성분 (WP-12-01)
  - CSM 검토 의견 반영 기록

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 릴리스 산출물에서 post-development 사이버보안 요구 목록을 확보하고, 각 요구의 생산 적용 여부(양산 공정 영향 유무)를 1차 분류한다.
2. 대상 품목의 양산 공정 단계도(투입→가공→조립→검사→출하)를 생산관리로부터 확보한다.
3. 직전 유사 품목의 생산 통제 계획(있으면)을 참조 기준선으로 확보한다.

### 5.2 수행 단계
1. **post-dev 요구 매핑**
   - post-development 요구 각 항목을 생산 공정 단계에 매핑한다.
   - 생산에 영향 없는 요구(운영·필드 단계 한정)는 "생산 비적용" 사유와 함께 별도 표기한다. (VCSMS-R-094 / [RQ-12-01])
2. **통제 항목 정의 — 4대 필수 요소**
   - 계획에 다음을 빠짐없이 기재한다 (VCSMS-R-095 / [RQ-12-02]):
     - (a) **생산 단계**: 각 사이버보안 통제가 적용되는 공정 위치
     - (b) **사용 도구·설비**: 키 주입·서명·플래싱 등에 쓰는 도구와 그 통제 수단
     - (c) **무단 변경 방지 통제 연계**: WI-VCSMS-02-07-02 에서 정의할 통제의 적용 지점 표기(상세 정의는 후속 WI)
     - (d) **요구 충족 확인법**: 각 요구가 충족되었음을 양산 중 확인하는 방법(검사·측정·기록)
3. **확인 방법·합격기준 명시**
   - 각 통제 항목에 대해 측정 가능한 합격기준과 기록 방식을 지정한다.
   - 샘플링 검사 시 검사 빈도·표본 크기 근거를 기재한다.
4. **CSM 검토 의뢰**
   - 작성한 계획서를 CSM 에 검토 의뢰한다.
   - CSM 검토 의견(요구 누락·통제 적정성)을 반영한다.
5. **승인 요청**
   - Project CS Lead 에게 승인 요청한다(전자결재 또는 PCB 기록).
   - 승인 후 계획서 frontmatter 의 `status` 를 승인 상태로 갱신하고 버전을 확정한다.

### 5.3 완료 조건
- [ ] post-development 요구 전 항목이 생산 공정에 매핑되었다 (비적용 항목은 사유 기재)
- [ ] 계획서에 4대 필수 요소(단계·도구·무단변경방지통제·확인법)가 모두 포함되었다
- [ ] 각 통제 항목에 측정 가능한 합격기준이 지정되었다
- [ ] CSM 검토 의견이 반영되었다
- [ ] Project CS Lead 승인이 완료되었다

## 6. 인터페이스 부서
- **생산관리/QMS**: 양산 공정 흐름·작업표준서 제공
- **CSM 조직**: post-development 요구 해석·검토
- **품질보증**: 검사·합격기준 정합성 협의

## 7. 주의사항 / 예외 처리

### 7.1 post-dev 요구 누락·불명확
- 릴리스 산출물에 생산 적용 요구가 명시되지 않았거나 해석이 모호하면, 임의 판단하지 않고 PRO-VCSMS-02-02(릴리스) 담당에게 질의·확인한다. 확인 전 해당 항목은 "보류"로 표기하고 계획 승인에서 제외한다.

### 7.2 양산 공정 변경 발생
- 계획 작성 후 공정 변경(설비 교체·라인 이설)이 발생하면, 변경된 단계에 한해 매핑·통제 항목을 재검토하고 계획서를 개정한다(경미 시 v0.x 증분). 영향이 4대 요소 구조에 미치면 CSM 재검토를 거친다.

### 7.3 도구·설비 미가용
- 계획상 필요한 통제 도구(예: 서명 키 주입 설비)가 양산 시점에 미가용이면, 대체 통제(수동 검증·임시 격리)를 정의하고 그 한계를 명시한 뒤 CSM·Project CS Lead 의 위험 수용 결정을 받는다.
