# 통합·검증 활동 수행 (WI-VCSMS-02-05-05)

> 상위 절차: [[PRO-VCSMS-02-05_제품개발_사이버보안_엔지니어링_절차]] · 상위 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
통합·검증 활동을 사양·양산형상·기능역량·가이드라인 적합성을 고려하여 명시·수행함으로써, 구현·통합 결과가 사이버보안 사양을 충족함을 확인하고 그 증적을 남긴다.

## 2. 수행 주체
- **주 수행자**: 검증 엔지니어
- **검토자**: 보안 설계자, 개발자
- **승인자**: Cybersecurity Manager (CSM) (검증 엔지니어가 활동 R/A)

## 3. 범위
ISO/SAE 21434 §10.4.2([RQ-10-09], [RQ-10-10])에 적용한다. 본 지침은 통합·검증 활동 명세와 수행·결과 기록을 다룬다. 커버리지 평가·취약점 테스트는 후속 WI-05-06 이 담당하며, 차량 수준 검증(Clause 11)과 구별된다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-05-01-01_사이버보안_사양서]] (검증 통과 사양, WP-10-01)
  - [[TMP-VCSMS-02-05-04-01_사양_검증보고서]] (통과 판정)
  - 양산형상 정보·기능역량·가이드라인
- **Output**
  - [[TMP-VCSMS-02-05-05-01_통합_검증_활동_명세_및_보고서]] 작성분 (WP-10-06 명세, WP-10-07 보고)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 사양 검증이 통과(WI-05-04 done) 상태인지 확인한다(entry_gate).
2. 통합 대상 컴포넌트·양산형상·테스트 환경을 확인한다.
3. 통합·검증 명세/보고서 양식([[TMP-VCSMS-02-05-05-01_통합_검증_활동_명세_및_보고서]])을 발번한다.

### 5.2 수행 단계
1. **통합·검증 활동 명세** ([RQ-10-10])
   - 각 사양(SP-##) 충족 확인을 위한 통합·검증 활동(VA-##)을 명세한다.
   - 양산형상·기능역량·가이드라인 적합성을 고려해 활동 범위·방법·환경을 정한다.
2. **통합·검증 수행** ([RQ-10-09])
   - 명세된 활동을 수행하고 사양 충족 여부를 컴포넌트·통합 수준에서 확인한다.
3. **결과 기록·판정**
   - 각 활동의 합격/불합격과 증적(로그·캡처·측정값)을 기록한다.
   - 불합격 사양은 부적합으로 기록하고 처리 방향(재작업·약점 등록)을 연결한다.
4. **추적성 연결**
   - 사양(SP-##)↔검증활동(VA-##)↔결과의 추적을 연결한다.
5. **검토·승인**
   - 보안 설계자·개발자 검토를 반영하고 CSM 승인을 받는다.

### 5.3 완료 조건
- [ ] entry_gate(WI-05-04 done) 충족 확인
- [ ] 모든 사양(SP-##)에 통합·검증 활동(VA-##) 명세(누락 0)
- [ ] 통합·검증 수행 및 합격/불합격 판정 기록
- [ ] 불합격 사양 처리 방향 연결
- [ ] SP↔VA↔결과 추적 연결 확인
- [ ] CSM 승인 기록 확보

## 6. 인터페이스 부서
- **검증 엔지니어**: 커버리지 평가·취약점 테스트로 진행([[WI-VCSMS-02-05-06_테스트_커버리지_평가_및_취약점_테스트]])
- **개발자**: 불합격 시 구현 재작업
- **형상관리팀**: 양산형상 정보 제공([RQ-05-11] 경계면 참조)

## 7. 주의사항 / 예외 처리

### 7.1 검증 불합격(재작업)
- 사양 불합격 시 해당 컴포넌트 구현(WI-05-02)으로 재작업을 연계하거나, 사양 결함이면 사양(WI-05-01)으로 반려한다. 재작업 후 해당 활동을 재수행한다.

### 7.2 환경·형상 불일치
- 테스트 환경이 양산형상과 불일치하면, 차이를 기록하고 차량 수준 검증(Clause 11)에서 보완 검증할 항목으로 이연 표식한다.

### 7.3 통합 불가(의존 컴포넌트 미준비)
- 의존 컴포넌트 미준비로 통합 불가하면, 스텁·시뮬레이터로 부분 검증하고 미통합 항목·재검증 시점을 명시한다.
