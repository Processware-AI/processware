# 보안 릴리스 검증 및 동반문서·무결성·키관리 (WI-MDCS-01-02-08)

> 상위 절차: [[PRO-MDCS-01-02_보안_SW_개발_프로세스_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
릴리스 직전에 보안 발견 사항의 Clause 9 종결을 검증하고, 동반문서(운영·계정·잔여 리스크)를 확정하며, 배포 파일의 무결성·코드서명 키 보호를 보장하고, 미해결 보안 이슈가 없는 상태에서만 출시함을 검증하여, 보안 개발 프로세스를 완료한다. (5.8.1~5.8.7)

## 2. 수행 주체
- **주 수행자**: 릴리스 책임자
- **검토자**: 보안책임자(PSO)
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-01-02 §5 단계8(릴리스)에 적용한다. **선행조건**: WI-MDCS-01-02-07(시스템 시험) 완료. 모든 릴리스에 적용한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 시스템 시험 결과·발견 종결 현황(WI-MDCS-01-02-07)
  - 잔여 리스크 목록(PRO-MDCS-02-01)
  - 동반문서 초안·코드서명 키관리 정책
- **Output**
  - [[TMP-MDCS-01-02-08-01_보안_릴리스검증_체크리스트_v0.1]] 작성분
  - 릴리스 검증 기록(게이트별 합격/불합격)
  - 확정 동반문서·무결성/서명 증적

## 5. 수행 절차

### 5.1 사전 준비
1. 시스템 시험·문제해결의 발견 종결 현황을 집계한다.
2. 동반문서 초안과 잔여 리스크 목록을 확보한다.
3. 코드서명 키관리·무결성 검증 방법을 확인한다.

### 5.2 수행 단계
1. **발견 종결 검증**
   - 모든 시험·검토 발견이 Clause 9(문제해결)로 종결되었는지 검증한다.
2. **동반문서 확정**
   - 보안 운영·계정 관리 지침과 잔여 리스크 안내가 동반문서에 포함·정확함을 확인한다(WI-MDCS-01-01-05 검토 결과 반영).
3. **무결성·키 보호**
   - 배포 파일의 무결성 검증 수단(해시·서명)을 적용하고, 코드서명 키의 보호(접근 통제·HSM)를 확인한다.
4. **미해결 이슈 게이트**
   - 미해결(수용 불가) 보안 이슈가 없음을 검증한다. 잔여 리스크는 정식 승인 상태여야 한다.
5. **프로세스 완료·폐기 지침**
   - 보안 개발 프로세스 산출물 완비를 확인하고, 안전한 폐기 지침을 동반문서에 포함한다.
6. **릴리스 승인**
   - PSO 가 릴리스 게이트 전부 합격을 확인·승인한다.

### 5.3 완료 조건
- [ ] 모든 시험·검토 발견이 Clause 9 로 종결됨
- [ ] 동반문서에 운영·계정·잔여 리스크·폐기 지침 포함·정확
- [ ] 배포 파일 무결성(해시/서명) 적용
- [ ] 코드서명 키 보호(접근 통제·HSM) 확인
- [ ] 미해결(수용 불가) 보안 이슈 0건, 잔여 리스크 정식 승인
- [ ] PSO 릴리스 승인 기록 존재

## 6. 인터페이스 부서
- **PRO-MDCS-01-05(문제해결)**: 발견 종결 확인
- **PRO-MDCS-02-01(리스크 관리)**: 잔여 리스크 승인
- **WI-MDCS-01-01-05(동반문서 검토)**: 동반문서 보안 검토 결과
- **DevOps/배포**: 무결성·서명 적용

## 7. 주의사항 / 예외 처리

### 7.1 미해결 이슈로 릴리스 차단
- 미해결 고위험 이슈가 있으면 릴리스를 차단한다. 예외적으로 잔여 리스크 수용 시 PSO·리스크 관리의 정식 승인과 동반문서 안내가 선행되어야 한다.

### 7.2 코드서명 키 노출 의심
- 코드서명 키 노출이 의심되면 즉시 키를 폐기·재발급하고 영향 받은 배포물을 재서명하며 PRO-MDCS-01-05 로 사건을 처리한다.

### 7.3 동반문서 미완성
- 동반문서에 잔여 리스크·운영 지침이 누락되면 릴리스를 보류하고 WI-MDCS-01-01-05 로 보완 후 재검증한다.

### 7.4 긴급 보안 릴리스(hot-fix)
- 취약점 긴급 패치 릴리스는 축약 게이트로 진행하되, 무결성·미해결 이슈 게이트는 생략하지 않으며 사후 정식 검증을 보완한다.
