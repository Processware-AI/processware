# 보안 리스크 추정 및 평가(CVSS·수용 판정) (WI-MDCS-02-01-03)

> 상위 절차: [[PRO-MDCS-02-01_보안_리스크_관리_프로세스_절차_v0.1]] · 상위 방침: [[POL-MDCS-02_보안_리스크_관리_방침_v0.1]]

## 1. 업무 목적
위협 모델에서 식별된 취약점·위협의 리스크를 CVSS·MITRE 등 일관된 방법으로 추정하고, 수용 기준(방침)에 따라 수용 가능 여부를 평가하며, 평가 결과로 위협 모델 갱신을 통지하여, 리스크 통제 우선순위를 결정한다. (7.3)

## 2. 수행 주체
- **주 수행자**: 보안책임자(PSO)
- **검토자**: 위협 모델링 리드
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-02-01 §5 단계3(추정·평가)에 적용한다. **선행조건**: WI-MDCS-02-01-02(위협 모델링) 완료. 위협 모델 갱신 시 재수행한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 위협 모델(WI-MDCS-02-01-02)
  - 보안 맥락(WI-MDCS-02-01-01)
  - 리스크 수용 기준(POL-MDCS-02)
- **Output**
  - [[TMP-MDCS-02-01-03-01_보안_리스크_추정_및_평가표_v0.1]] 작성분
  - 리스크 추정 결과(점수·맥락 보정)
  - 수용 평가 결과(통제 필요 여부)

## 5. 수행 절차

### 5.1 사전 준비
1. 위협 모델과 리스크 수용 기준을 확보한다.
2. 추정 방법(CVSS/MITRE)을 확정한다.

### 5.2 수행 단계
1. **리스크 추정**
   - 각 위협의 리스크를 CVSS/MITRE 로 추정하고 보안 맥락·방어 심층화를 반영한다.
2. **수용 평가**
   - 추정 점수를 수용 기준과 비교해 수용 가능/통제 필요로 판정한다.
3. **우선순위 결정**
   - 통제 필요 항목의 우선순위를 정한다.
4. **위협 모델 갱신 통지**
   - 평가 결과(신규 리스크·변동)를 위협 모델·관계자에게 통지한다.
5. **검토·연계**
   - PSO 검토 후 리스크 통제(WI-MDCS-02-01-04)로 연계한다.

### 5.3 완료 조건
- [ ] 각 위협 리스크가 일관된 방법(CVSS/MITRE)으로 추정됨
- [ ] 보안 맥락·방어 심층화 반영
- [ ] 수용 기준 대비 수용 가능/통제 필요 판정
- [ ] 통제 필요 항목 우선순위 결정
- [ ] 위협 모델 갱신 통지
- [ ] PSO 검토·리스크 통제 연계

## 6. 인터페이스 부서
- **WI-MDCS-02-01-02(위협 모델링)**: 위협 입력
- **WI-MDCS-02-01-04(리스크 통제)**: 통제 필요 항목 연계
- **제품 리스크 관리(연계)**: 안전·유효성 리스크 협력

## 7. 주의사항 / 예외 처리

### 7.1 CVSS 맥락 미반영
- CVSS 기본 점수만 사용하면 실제 리스크와 괴리될 수 있으므로, 보안 맥락(노출·방어심층화)을 반영한 보정 점수를 함께 기록한다.

### 7.2 수용 기준 경계 사례
- 수용/통제 경계에 걸친 리스크는 보수적으로 통제 필요로 분류하거나, 안전 영향이 있으면 우선순위를 상향한다.

### 7.3 안전 영향 리스크
- 안전·유효성에 영향을 주는 리스크는 보안 점수와 무관하게 제품 리스크 관리와 협력하여 별도 평가한다.

### 7.4 추정 방법 변경
- 추정 방법(예: CVSS 버전)이 변경되면 이전 평가와의 일관성을 위해 재추정 기준을 명시한다.
