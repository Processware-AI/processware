# 미해결 보안이슈 정기 검토(릴리스별) (WI-MDCS-01-05-06)

> 상위 절차: [[PRO-MDCS-01-05_보안_문제해결_프로세스_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
종결되지 않은 미해결 보안 이슈를 최소 각 릴리스 시점마다 정기 검토하여, 처리·잔여 리스크 수용·에스컬레이션을 결정하고, 누적·방치되는 보안 이슈가 없도록 관리한다. (9.5-REQ-006)

## 2. 수행 주체
- **주 수행자**: 보안책임자(PSO)
- **검토자**: 보안운영위원회(PSGB)
- **승인자**: 보안운영위원회(PSGB)

## 3. 범위
PRO-MDCS-01-05 §5 단계6(정기 검토)에 적용한다. 최소 각 릴리스 시점에 수행하며, 미해결 이슈가 누적되면 추가 검토한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 미해결 보안 이슈 목록(접수·처리 대장)
  - 잔여 리스크 평가(PRO-MDCS-02-01)
  - 영향평가 기준(WI-MDCS-01-03-01)
- **Output**
  - [[TMP-MDCS-01-05-06-01_미해결_보안이슈_정기검토표_v0.1]] 작성분
  - 정기 검토 기록(이슈별 결정)
  - 에스컬레이션·수용·처리 연계

## 5. 수행 절차

### 5.1 사전 준비
1. 미해결 보안 이슈를 집계한다(상태·심각도·경과 시간).
2. 잔여 리스크·영향평가 기준을 확보한다.

### 5.2 수행 단계
1. **현황 집계**
   - 미해결 이슈를 심각도·경과 시간·릴리스 영향으로 정리한다.
2. **이슈별 검토**
   - 각 이슈에 대해 즉시 처리·잔여 리스크 수용·에스컬레이션을 결정한다.
3. **릴리스 영향 판정**
   - 미해결 이슈가 릴리스 게이트(WI-MDCS-01-02-08)에 미치는 영향을 판정한다.
4. **결정·연계**
   - 처리는 WI-MDCS-01-05-04 로, 수용은 정식 잔여 리스크 승인(PRO-MDCS-02-01)으로 연계한다.
5. **검토·승인**
   - PSGB 가 검토 결과를 승인하고 다음 검토 시점을 정한다.

### 5.3 완료 조건
- [ ] 미해결 이슈 전수 집계(누락 0건)
- [ ] 각 이슈에 대해 처리/수용/에스컬레이션 결정
- [ ] 릴리스 게이트 영향 판정
- [ ] 처리·수용 결정이 적절히 연계됨
- [ ] PSGB 검토·승인 및 다음 검토 시점 확정

## 6. 인터페이스 부서
- **WI-MDCS-01-05-04(처리)**: 처리 결정 이슈 연계
- **PRO-MDCS-02-01(리스크 관리)**: 잔여 리스크 정식 승인
- **WI-MDCS-01-02-08(릴리스)**: 릴리스 게이트 연계

## 7. 주의사항 / 예외 처리

### 7.1 고위험 이슈 누적
- 고위험 미해결 이슈가 누적되면 릴리스를 보류하거나 자원을 우선 투입하여 처리한다(방치 금지).

### 7.2 잔여 리스크 수용 남용 방지
- 반복적인 잔여 리스크 수용으로 이슈가 영구 미해결되지 않도록, 수용에는 기한·재평가 조건을 부여한다.

### 7.3 검토 주기 누락
- 릴리스가 장기간 없어 검토가 누락될 우려가 있으면 정기 주기(예: 분기)를 별도로 설정하여 검토를 보장한다.

### 7.4 새로운 정보로 영향 변동
- 미해결 이슈의 영향이 새 정보(악용 사례·CVSS 변동)로 상향되면 즉시 재처리·공개 절차로 에스컬레이션한다.
