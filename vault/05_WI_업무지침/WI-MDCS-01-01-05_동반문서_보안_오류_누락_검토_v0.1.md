# 동반문서 보안 오류·누락 검토 (WI-MDCS-01-01-05)

> 상위 절차: [[PRO-MDCS-01-01_보안_거버넌스_및_일반요건_관리_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
보안 운영·계정·잔여 리스크 지침을 포함한 동반문서의 보안 관련 오류·누락을 식별하고, 발견된 이슈를 종결까지 추적하여, 사용자가 정확한 보안 운영 정보를 제공받도록 보장한다. (4.1.9)

## 2. 수행 주체
- **주 수행자**: 프로세스 오너(문서 책임)
- **검토자**: 보안책임자(PSO)
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-01-01 §5 단계8(동반문서 검토)에 적용한다. 신규 릴리스·동반문서 개정 시 수행하며, 운영 중 사용자 피드백·이슈 발생 시 추가 검토한다. 동반문서 작성 자체는 WI-MDCS-01-02-08(릴리스)이 담당하고, 본 지침은 보안 관점의 검증을 다룬다.

## 4. 입력 자료 / 산출물
- **Input**
  - 동반문서(사용자 매뉴얼·보안 운영 지침·계정 관리 지침·잔여 리스크 안내)
  - 제품 보안 맥락·잔여 리스크 목록(PRO-MDCS-02-01 산출)
  - 사용자 피드백·CS 문의(해당 시)
- **Output**
  - [[TMP-MDCS-01-01-05-01_동반문서_보안검토_및_이슈추적표_v0.1]] 작성분
  - 검토 기록(검토 항목·발견 이슈)
  - 이슈 추적·종결 기록

## 5. 수행 절차

### 5.1 사전 준비
1. 검토 대상 동반문서를 수집하고 최신판 여부를 확인한다.
2. 제품 보안 맥락·잔여 리스크·계정/운영 통제 정보를 확보한다.
3. 검토 체크리스트(필수 보안 항목)를 준비한다.

### 5.2 수행 단계
1. **항목별 대조**
   - 동반문서가 다음 보안 항목을 정확·완전히 다루는지 대조한다:
     - 보안 운영·계정 관리 지침, 잔여 리스크 안내, 최소 환경 요건, 무결성 검증 방법.
2. **오류·누락 식별**
   - 부정확·구버전·누락된 보안 정보를 식별하고 이슈로 등록한다.
3. **영향 판단**
   - 각 이슈의 사용자 보안 영향을 판단하고 우선순위를 정한다.
4. **수정 의뢰·반영**
   - 문서 작성자에게 수정을 의뢰하고 반영 결과를 확인한다.
5. **종결 추적**
   - 모든 이슈가 종결될 때까지 상태를 추적하고, 종결 시 근거를 기록한다.
6. **검토 승인**
   - PSO 가 검토 완전성·이슈 종결을 확인·승인한다.

### 5.3 완료 조건
- [ ] 대상 동반문서 최신판 확인
- [ ] 필수 보안 항목 전수 대조 수행
- [ ] 발견된 오류·누락이 모두 이슈로 등록됨
- [ ] 각 이슈의 사용자 보안 영향·우선순위 판단
- [ ] 식별된 이슈가 모두 종결되거나 종결 일정 확정(미추적 0건)
- [ ] PSO 검토·승인 기록 존재

## 6. 인터페이스 부서
- **테크니컬 라이팅/문서팀**: 동반문서 작성·수정
- **PRO-MDCS-02-01(리스크 관리)**: 잔여 리스크 정보 제공
- **고객지원/CS**: 사용자 피드백·이슈 제보

## 7. 주의사항 / 예외 처리

### 7.1 출시 후 동반문서 오류 발견
- 출시된 동반문서에서 보안 영향 오류가 발견되면 즉시 정오표(errata) 또는 갱신을 배포하고, 사용자 보안 영향이 큰 경우 PRO-MDCS-01-05(문제해결)로 연계한다.

### 7.2 잔여 리스크 안내 누락
- 잔여 리스크가 동반문서에 누락되면 릴리스 검증(WI-MDCS-01-02-08)으로 에스컬레이션하여 보완 전 출시를 보류한다.

### 7.3 다국어/현지화 문서
- 번역본에서 보안 지침이 누락·왜곡되면 원본과 대조하여 수정하고, 모든 출시 언어판을 검토 대상에 포함한다.

### 7.4 이슈 장기 미종결
- 이슈가 정해진 기한 내 종결되지 않으면 사유를 기록하고 PSO 에 보고하여 우선순위를 재조정한다.
