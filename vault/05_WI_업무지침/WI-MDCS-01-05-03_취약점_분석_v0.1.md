# 취약점 분석(영향·근본원인·교차제품·안전유효성) (WI-MDCS-01-05-03)

> 상위 절차: [[PRO-MDCS-01-05_보안_문제해결_프로세스_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
조사로 적용 확인된 취약점에 대해 보안 맥락·방어 심층화·CVSS 를 고려한 영향 분석, 근본 원인 분석, 교차 제품 영향, 안전·유효성 영향을 종합 분석하여, 처리·공개 결정의 근거를 제공한다. (9.4)

## 2. 수행 주체
- **주 수행자**: 분석가
- **검토자**: 보안책임자(PSO)
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-01-05 §5 단계3(분석)에 적용한다. **선행조건**: WI-MDCS-01-05-02(조사) 완료. 적용 확인 건마다 수행한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 조사 기록(WI-MDCS-01-05-02)
  - 위협 모델·보안 맥락·방어심층화 정보(PRO-MDCS-02-01)
  - 제품 포트폴리오·공유 컴포넌트 정보
- **Output**
  - [[TMP-MDCS-01-05-03-01_취약점_분석_보고서_v0.1]] 작성분
  - 영향 분석(CVSS·맥락 보정)
  - 근본 원인·교차 제품·안전유효성 영향 분석

## 5. 수행 절차

### 5.1 사전 준비
1. 조사 기록과 위협 모델·보안 맥락을 확보한다.
2. 공유 컴포넌트·제품 포트폴리오를 확인한다(교차 영향용).

### 5.2 수행 단계
1. **영향 분석**
   - CVSS 기본 점수에 제품 보안 맥락·방어 심층화 효과를 반영해 실제 영향을 평가한다.
2. **근본 원인 분석(RCA)**
   - 취약점의 근본 원인(설계·구현·구성)을 분석한다.
3. **교차 제품 영향**
   - 공유 컴포넌트·유사 설계로 인한 타 제품 영향을 식별한다.
4. **안전·유효성 영향**
   - 취약점이 환자 안전·임상 유효성에 미치는 영향을 평가한다(제품 리스크 관리 협력).
5. **검토·연계**
   - PSO 검토 후 처리(WI-MDCS-01-05-04)로 연계한다.

### 5.3 완료 조건
- [ ] CVSS + 보안 맥락·방어심층화 반영 영향 평가
- [ ] 근본 원인 분석(RCA) 수행
- [ ] 교차 제품 영향 식별
- [ ] 안전·유효성 영향 평가(필요 시 제품 RM 협력)
- [ ] PSO 검토·처리 연계
- [ ] 분석 보고서 보존

## 6. 인터페이스 부서
- **PRO-MDCS-02-01(리스크 관리)**: 위협 모델·보안 맥락·잔여 리스크
- **제품 리스크 관리(연계)**: 안전·유효성 영향 협력
- **WI-MDCS-01-05-04(처리)**: 분석 결과 연계

## 7. 주의사항 / 예외 처리

### 7.1 CVSS 와 실제 영향 괴리
- CVSS 기본 점수가 높아도 방어 심층화로 실제 악용이 어려우면 맥락 보정을 명시하고, 반대로 낮아도 안전 영향이 크면 우선순위를 상향한다.

### 7.2 교차 제품 영향 확산
- 공유 컴포넌트 영향이 여러 제품에 확산되면 각 제품 라인에 통지하고, 통합 대응을 PSO 가 조율한다(9.5 교차 통지 연계).

### 7.3 안전 영향 중대
- 환자 안전에 중대한 영향이 있으면 제품 리스크 관리·규제 통지(WI-MDCS-01-05-05)를 즉시 병행한다.

### 7.4 분석 정보 부족
- 근본 원인이 불명확하면 추가 조사·재현을 요청하고, 잠정 분석으로 처리를 시작하되 확정 시 갱신한다.
