# 프로젝트 사이버보안 책임 배정 (WI-VCSMS-02-01-01)

> 상위 절차: [[PRO-VCSMS-02-01_프로젝트_사이버보안_관리_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]

## 1. 업무 목적
프로젝트 착수 시점에 사이버보안 활동의 책임과 권한을 명확한 담당자에게 배정하고 이해관계자에게 전파하여, 후속 컨셉·개발·검증 활동(Clause 9·10·11·15)이 책임 공백 없이 추적 가능하게 시작되도록 한다. (§6.4.1 [RQ-06-01], 조직 책임배정 [RQ-05-03] 계승)

## 2. 수행 주체
- **주 수행자**: Cybersecurity Manager (CSM)
- **검토자**: Project CS Lead
- **승인자**: Top Management (경영진) — 프로젝트 사이버보안 권한 위임 승인

## 3. 범위
본 지침은 PRO-VCSMS-02-01 §5 단계 1(책임 배정)에 적용한다. 조직 차원의 상위 역할 정의는 거버넌스 절차([[PRO-VCSMS-01-01_조직_사이버보안_거버넌스_운영_절차]])를 계승하며, 본 지침은 이를 프로젝트 단위로 구체화한다. 진척 추적 책임 배정([RQ-06-04] [RQ-05-04])을 포함한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 조직 사이버보안 역할 정의 (거버넌스 절차 산출물)
  - 프로젝트 헌장 / item·component 개요
  - 가용 인력·역량 목록
- **Output**
  - [[TMP-VCSMS-02-01-01-01_프로젝트_사이버보안_책임배정표]] 작성분 (RACI 형식)
  - 책임 배정 전파 기록 (배포 확인)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 조직 거버넌스 절차에서 정의된 사이버보안 역할(CSM·Assessor·CS Lead 등) 정의를 확인한다.
2. 프로젝트 헌장에서 사이버보안 관련 item/component 범위와 단계(컨셉/개발/생산)를 파악한다.
3. 가용 인력의 역량(역량 관리 경계면 §5.4.2 [RQ-05-07] 참조)을 확인하여 후보를 식별한다.

### 5.2 수행 단계
1. **핵심 역할 배정**
   - Project CS Lead, TARA 분석가, 보안 설계자, 검증 담당 각각에 책임자(R)와 책임승인자(A)를 지정한다.
   - 독립성이 요구되는 역할(독립 평가 Assessor)은 본 프로젝트 개발라인과 보고선이 분리되도록 배정한다.
2. **권한 명시**
   - 각 역할의 의사결정 권한(예: 테일러링 승인, 리스크 처리 결정)을 책임배정표에 명시한다.
   - 진척 추적·계획 유지 책임([RQ-06-04])을 Project CS Lead 에 배정한다.
3. **자원 확인**
   - 배정된 역할 수행에 필요한 자원(인시·도구·예산)이 확보되었는지 확인하고 미확보 항목은 경영진 에스컬레이션 대상으로 기록한다. ([RQ-06-04] [RQ-05-04])
4. **승인 획득**
   - 작성된 책임배정표를 경영진에게 제출하여 권한 위임을 승인받는다.
5. **전파**
   - 승인된 책임배정표를 프로젝트 전 구성원·인접 부서(안전·품질·구매)에 배포하고 수신 확인을 기록한다.

### 5.3 완료 조건
- [ ] 사이버보안 핵심 역할 전부에 R·A 가 배정됨 (공백 0)
- [ ] 독립 평가 역할의 보고선 분리 확인
- [ ] 진척 추적·계획 유지 책임이 명시적으로 배정됨
- [ ] 경영진 승인 획득
- [ ] 전 구성원·인접 부서 전파 및 수신 확인 기록

## 6. 인터페이스 부서
- **HR/역량관리**: 역량 검증 (§5.4.2 경계면)
- **품질(QMS)**: 책임배정표의 형상·문서 관리 (§5.4.4 경계면)
- **구매/SCM**: 분산 활동 시 공급자 측 책임 연계 (Clause 7)

## 7. 주의사항 / 예외 처리

### 7.1 1인 다역(소규모 프로젝트)
- 인력 제약으로 1인이 복수 역할 겸임 시:
  - 독립 평가 역할만은 겸임 금지(이해상충). 외부/사내 타 부서 Assessor 지정.
  - 겸임 사유와 보완 통제(상호검토 등)를 책임배정표 비고에 기록.

### 7.2 프로젝트 중 책임자 교체
- 핵심 역할 담당자 이탈·교체 시:
  - 24시간 내 임시 대행 지정, 5영업일 내 정식 재배정·재승인.
  - 인수인계 기록을 첨부하고 진행 중 활동의 책임 단절 여부를 점검.

### 7.3 자원 미확보
- 필요 자원이 확보되지 않은 경우:
  - 미확보 항목을 명시해 경영진에 에스컬레이션하고, 자원 확보 전까지 해당 활동을 계획상 보류로 표기.
  - 무리한 일정 강행 금지 — 테일러링 검토(WI-04)로 회부.
