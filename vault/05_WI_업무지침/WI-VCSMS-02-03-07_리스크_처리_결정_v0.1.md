# 리스크 처리 결정 (회피/감소/공유/보유) (WI-VCSMS-02-03-07)

> 상위 절차: [[PRO-VCSMS-02-03_위협분석_및_리스크평가_TARA_절차]] · 정책: [[POL-VCSMS-02_차량_사이버보안_엔지니어링_정책]]
> **횡단 방법론** — TARA 7단계(최종). 처리 결과는 호출 절차(컨셉 §9.4·취약점 §8.6)로 반환.

## 1. 업무 목적
각 위협 시나리오의 리스크값을 기반으로 리스크 처리 옵션(회피/감소/공유/보유)을 결정하고, 결정 결과를 호출 절차(컨셉 단계 사이버보안 목표·클레임, 취약점 관리)로 반환하여, TARA 사이클을 종결한다. (§15.9 [RQ-15-17])

## 2. 수행 주체
- **주 수행자**: Cybersecurity Manager (CSM)
- **검토자**: TARA 분석가 / 안전 담당
- **승인자**: Cybersecurity Manager (CSM)

## 3. 범위
본 지침은 PRO-VCSMS-02-03 §5 단계 7(리스크 처리)에 적용한다. 리스크값 산정표(WI-06)를 입력으로 받아 리스크 처리 결정(WP-15-08)을 산출한다. 처리 결과는 컨셉 절차(§9.4 [RQ-09-04~06]: 목표/클레임)와 취약점 관리(§8.6 [RQ-08-07])로 반환된다.

## 4. 입력 자료 / 산출물
- **Input**
  - [[TMP-VCSMS-02-03-06-01_리스크값_산정표]] (승인)
  - 조직 리스크 수용 기준 (acceptance criteria)
- **Output**
  - [[TMP-VCSMS-02-03-07-01_리스크_처리_등록부]] 작성분 (WP-15-08)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. 리스크값 산정표가 승인되었는지 확인한다(entry_gate).
2. 조직 리스크 수용 기준(어느 리스크값부터 처리가 필요한지)을 확인한다.

### 5.2 수행 단계
1. **처리 옵션 결정**
   - 각 위협 시나리오에 대해 회피(avoid)/감소(reduce)/공유(share)/보유(retain) 중 처리 옵션을 결정한다([RQ-15-17]).
   - 수용 기준 초과 리스크는 보유 불가(감소/회피/공유 필요).
2. **반환 산출물 매핑**
   - 감소 결정: 컨셉 단계 사이버보안 목표(§9.4 [RQ-09-05])로 매핑.
   - 공유·가정기반 보유 결정: 사이버보안 클레임(§9.4 [RQ-09-06])으로 매핑.
   - 취약점 관리 호출 시: §15.9 처리 또는 즉시 제거(§8.6 [RQ-08-07])로 매핑.
3. **잔여 리스크 명시**
   - 처리 후 잔여 리스크와 정당화를 등록부에 명시한다.
4. **검토·승인·반환**
   - TARA 분석가·안전 담당 검토 후 CSM 이 등록부를 승인하고, 결과를 호출 절차로 반환한다.

### 5.3 완료 조건
- [ ] 각 위협의 처리 옵션(회피/감소/공유/보유) 결정
- [ ] 수용 기준 초과 리스크의 보유 금지 확인
- [ ] 처리 결정의 반환 산출물(목표/클레임/취약점) 매핑
- [ ] 잔여 리스크·정당화 명시
- [ ] CSM 승인 + 호출 절차로 반환

## 6. 인터페이스 부서
- **컨셉 절차(PRO-VCSMS-02-04)**: 목표/클레임 반환 (§9.4)
- **취약점 관리(PRO-VCSMS-01-03)**: 취약점 처리 반환 (§8.6)
- **안전 담당(ISO 26262)**: 안전 연계 리스크 처리 정합
- **품질(QMS)**: 산출물 형상·문서 관리 (§5.4.4 경계면)

## 7. 주의사항 / 예외 처리

### 7.1 수용 기준 초과 보유 시도
- 수용 기준을 초과하는 리스크를 보유(retain)하려는 경우:
  - 금지. 감소/회피/공유로 전환하거나, 예외 보유는 경영진 명시 승인·근거 기록을 필수 조건으로 함.

### 7.2 처리 미정(미처리) 잔존
- 리스크값이 산정되었으나 처리가 결정되지 않은 위협이 있는 경우:
  - KPI(리스크값 대비 미처리 0건) 위반. 전수 처리 결정을 강제.

### 7.3 처리 후 리스크 재상승
- 처리(감소) 통제가 무력화되거나 신규 위협으로 리스크가 재상승한 경우:
  - TARA 를 재호출(WI-01~06 갱신)하고 처리 결정을 재수립.
