# 조직 프로세스 적합성 감사 수행 (WI-VCSMS-01-02-02)

> 상위 절차: [[PRO-VCSMS-01-02_독립_조직_사이버보안_감사_절차]] · 상위 정책: [[POL-VCSMS-01_자동차_사이버보안_거버넌스_정책]]

## 1. 업무 목적
승인된 감사 계획에 따라 조직 사이버보안 프로세스의 **적합성을 점검하고 객관적 증거를 수집**하여, 부적합·관찰 등 **발견사항을 식별**한다. ISO/SAE 21434 목적 달성 여부를 판정 가능한 증거 기반으로 정리한다.

## 2. 수행 주체
- **주 수행자**: Auditor (감사인)
- **검토자**: 주심사원 (Lead Auditor)
- **승인자**: 주심사원 — 발견사항 확정

## 3. 범위
PRO-VCSMS-01-02 §5 단계 3 에 적용한다. 프로세스 적합성 점검·증거 수집·발견사항 식별(§5.4.7 [RQ-05-17])을 다룬다. 감사 계획·독립성은 선행 [[WI-VCSMS-01-02-01_사이버보안_감사_계획_및_독립성_확보]] 전제(entry_gate). 보고·후속 조치는 [[WI-VCSMS-01-02-03_조직_사이버보안_감사_보고_및_후속조치]] 로 분리한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 승인된 사이버보안 감사 계획서([[WI-VCSMS-01-02-01_사이버보안_감사_계획_및_독립성_확보]] 산출물)
  - 피감 프로세스 산출물(거버넌스 WP-05·지속활동 WP-08·사고대응 WP-13)
  - 적합성 판정 기준(표준 조항·사내 규칙)
- **Output**
  - 감사 체크리스트(점검 항목·증거·판정)
  - 발견사항 목록(부적합·관찰·우수사례)
  - [[TMP-VCSMS-01-02-02-01_감사_체크리스트_및_발견사항]] 작성분
  - 증거 인덱스(MAT-005 심사증적 인덱스 연계)

## 5. 수행 절차 (단계별)

### 5.1 사전 준비
1. entry_gate 확인: WI-VCSMS-01-02-01 이 `done`(계획 승인·독립성 확보) 인지 확인.
2. 감사 계획서의 범위·기준·일정·증거 접근 권한 재확인.
3. 점검 항목을 적합성 기준에서 도출하여 체크리스트 초안 작성.

### 5.2 수행 단계
1. **체크리스트 확정**
   - 각 피감 프로세스(거버넌스·지속활동·사고대응)에 대해 표준 조항·사내 규칙 기반 점검 항목을 확정.
2. **증거 수집·점검**
   - 문서 검토·인터뷰·기록 추적으로 각 항목의 적합성을 점검.
   - 객관적 증거(문서 ID·기록·인터뷰 메모)를 수집하여 항목별로 연결.
3. **발견사항 식별·분류**
   - 각 항목을 적합/부적합/관찰/우수사례로 판정.
   - 부적합은 중대도(major/minor)와 근거 조항을 명시.
   - [[TMP-VCSMS-01-02-02-01_감사_체크리스트_및_발견사항]] 에 기록.
4. **현장 확인·반론 청취**
   - 피감 조직에 발견사항 초안을 제시하고 사실관계·반론을 청취.
   - 사실 오인은 정정, 유효 발견사항은 유지.
5. **주심사원 확정**
   - 주심사원이 발견사항의 일관성·증거 충분성을 검토·확정.
6. **증거 인덱싱**
   - 수집 증거를 인덱스화하여 [[MAT-005_심사증적_인덱스]] 와 연계(추적 가능성 확보).

### 5.3 완료 조건
- [ ] 피감 프로세스별 점검 항목 체크리스트 확정
- [ ] 각 항목에 객관적 증거 연결(증거 없는 판정 0건)
- [ ] 발견사항 적합/부적합/관찰/우수 분류 및 부적합 중대도·근거 조항 명시
- [ ] 피감 조직 반론 청취·사실관계 확인 완료
- [ ] 주심사원 발견사항 확정
- [ ] 증거 인덱스 작성·MAT-005 연계 완료

## 6. 인터페이스 부서
- **피감 조직(CSM·모니터링·사고대응)**: 증거 제공·인터뷰
- **내부심사 사무국(§9.2)**: 심사 방법론 정본 — 본 지침은 참조
- **MAT-005 운영**: 증거 인덱스 연계

## 7. 주의사항 / 예외 처리

### 7.1 증거 접근 거부·부재
- 계획된 증거에 접근이 거부되거나 증거가 부재한 경우:
  - 접근 거부는 한계(limitation)로 기록하고 경영진 권한으로 재요청.
  - 증거 부재 자체가 부적합 근거일 수 있으므로 그대로 발견사항화.

### 7.2 감사 중 중대 리스크 발견
- 감사 중 즉각 대응이 필요한 중대 사이버보안 리스크를 발견한 경우:
  - 보고서 완성 전이라도 즉시 CSM·경영진에 긴급 통지(에스컬레이션).
  - 필요 시 사고대응 PRO-01-04 또는 지속활동 PRO-01-03 연계.

### 7.3 피감 조직과 사실관계 불일치
- 발견사항에 대해 피감 조직과 사실관계가 합의되지 않는 경우:
  - 양측 입장을 모두 기록하고 증거 우위로 판정.
  - 최종 판단은 주심사원이 하고, 이의는 보고 단계에서 처리.
