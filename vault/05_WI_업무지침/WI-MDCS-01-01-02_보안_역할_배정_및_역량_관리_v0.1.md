# 보안 역할 배정 및 역량 관리 (WI-MDCS-01-01-02)

> 상위 절차: [[PRO-MDCS-01-01_보안_거버넌스_및_일반요건_관리_절차_v0.1]] · 상위 방침: [[POL-MDCS-01_헬스SW_제품_보안_거버넌스_방침_v0.1]]

## 1. 업무 목적
보안 수명주기에서 요구되는 활동별로 책임 역할을 지정·문서화하고, 각 역할에 필요한 보안 역량 요건을 정의하여 교육·평가를 통해 충족함으로써, 보안 활동을 수행할 인력의 자격을 보장한다. (4.1.2, 4.1.4)

## 2. 수행 주체
- **주 수행자**: 보안책임자(PSO) — 역할 배정 / 인사·교육 담당 — 역량 운영
- **검토자**: 보안운영위원회(PSGB)
- **승인자**: 보안책임자(PSO)

## 3. 범위
PRO-MDCS-01-01 §5 단계3~4(역할 배정·역량 관리)에 적용한다. 조직 단위로 수립하고, 조직 개편·신규 활동 도입·인력 변동 시 갱신한다.

## 4. 입력 자료 / 산출물
- **Input**
  - 보안 수명주기 활동 목록(개발·유지보수·리스크·문제해결 등)
  - 역할기술서·조직도
  - 인력 현황·기존 교육 이력
- **Output**
  - [[TMP-MDCS-01-01-02-01_보안역할_배정_및_역량관리대장_v0.1]] 작성분
  - 활동별 역할 배정표(RACI 연계)
  - 역할별 역량 요건·교육 계획·역량 평가 결과

## 5. 수행 절차

### 5.1 사전 준비
1. 표준이 요구하는 보안 활동 목록을 정리한다(각 PRO 의 RACI 참조).
2. 현 조직의 역할·인력 현황을 확인한다.
3. 역할별 기존 보안 교육·자격 이력을 수집한다.

### 5.2 수행 단계
1. **역할 배정**
   - 각 보안 활동에 책임 역할(예: PSO·보안 아키텍트·보안 테스터·분석가)을 지정하고 문서화한다.
   - 한 활동의 Accountable 은 1명 원칙을 적용한다.
2. **역량 요건 정의**
   - 역할별로 요구되는 보안 지식·기술·경험 요건을 정의한다(예: 위협 모델링, 정적분석, 취약점 분석).
3. **격차 분석**
   - 현 인력의 역량과 요건을 대조해 격차를 식별한다.
4. **교육·확보 계획**
   - 격차 해소를 위한 교육·외부 채용·외부 전문가 활용 계획을 수립·실행한다.
5. **역량 평가·기록**
   - 교육 이수·평가 결과를 기록하고 역할 적격성을 판정한다.
6. **검토·승인**
   - PSGB 검토 후 PSO 가 승인한다. 배정표·역량 기록을 거버넌스 산출물로 등록한다.

### 5.3 완료 조건
- [ ] 모든 보안 활동에 책임 역할이 지정됨(미지정 활동 0건)
- [ ] 각 활동의 Accountable 1명 원칙 준수
- [ ] 역할별 보안 역량 요건이 정의됨
- [ ] 역량 격차에 대한 교육/확보 계획 수립·실행
- [ ] 역할별 역량 평가·교육 이수 기록 존재
- [ ] PSGB 검토·PSO 승인 기록 존재

## 6. 인터페이스 부서
- **인사/교육**: 교육 과정 제공·이수 관리
- **각 프로세스 오너**: 활동별 역할 후보·업무 내용 제공
- **PSGB**: 역할 배정·역량 체계 검토

## 7. 주의사항 / 예외 처리

### 7.1 역량 미충족 인력의 활동 수행 불가
- 요구 역량을 충족하지 못한 인력은 해당 보안 활동을 단독 수행할 수 없다. 교육 완료 또는 적격자 감독 하에서만 참여시킨다.

### 7.2 이해상충(테스터-개발자 등)
- 동일 인력이 개발과 독립 검토·시험을 겸하는 경우 이해상충을 관리한다(독립성 부족 시 외부/타 인력 배정). 상세는 WI-MDCS-01-02-07 §7 참조.

### 7.3 외부 전문가 활용
- 내부 역량 확보가 어려운 전문 영역(예: 침투 시험)은 외부 전문가를 활용하되, 그 자격·계약을 문서화하고 결과 검토 책임은 내부 역할이 보유한다.

### 7.4 인력 변동
- 핵심 보안 역할 담당자 이탈 시 후임 지정·인수인계·재교육을 완료할 때까지 해당 활동은 대행자를 지정하여 공백을 방지한다.
