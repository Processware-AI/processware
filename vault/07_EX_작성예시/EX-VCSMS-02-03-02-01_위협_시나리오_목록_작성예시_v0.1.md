# 위협 시나리오 목록 작성예시 (EX-VCSMS-02-03-02-01)

> 원본 양식: [[TMP-VCSMS-02-03-02-01_위협_시나리오_목록]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 대상 (예시)
| 항목 | 예시값 |
|---|---|
| item/component | 중앙 게이트웨이 item "GW-X2" |
| 자산 목록 참조 | WP-15-02 GW-X2 v1.0 |
| TARA 차수 / 작성일 | 1차 / 2026-06-24 |

## 2. 위협 시나리오 목록 (예시)
| 위협 ID | 대상 자산 ID | 손상 속성 | 손상 원인(위협) | 연결 피해 ID |
|---|---|---|---|---|
| TS-01 | A-01 OTA 펌웨어 | 무결성 | 서명 검증 우회로 위조 펌웨어 주입 | DS-01 |
| TS-02 | A-02 라우팅 메시지 | 무결성 | CAN-FD 메시지 스푸핑(인증 부재) | DS-02 |
| TS-03 | A-03 진단 세션 키 | 기밀성 | 키 추출(사이드채널/메모리 덤프) | DS-03 |

## 작성 시 유의사항
- 위협 시나리오는 "자산 + 손상 속성 + 손상 원인" 3요소를 모두 적는다.
- 모든 위협을 대응 피해 시나리오(DS)와 연결해 추적성을 확보한다.
- 실현성이 낮아 보여도 임의 삭제하지 않는다(타당성은 WI-05에서 판단).

## 잘못된 작성 사례
> ❌ "위협: 해킹" — 자산·속성·원인 불명
> ✅ "TS-02 / A-02 / 무결성 / CAN-FD 스푸핑(인증 부재)"
> ❌ 피해 시나리오 연결 공란 — 영향 평가 추적 단절
