# 차량 수준 사이버보안 검증 보고서 작성예시 (EX-VCSMS-02-06-03-01)

> 원본 양식: [[TMP-VCSMS-02-06-03-01_차량_수준_사이버보안_검증_보고서]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성. (가상 RKE 예시)

## 0. 문서 정보
| 항목 | 내용 |
|---|---|
| 아이템/차량명 | MY27 RKE / 프로토 차량 #2 |
| 검증 기간 | 2026-W11~W12 |
| 작성자 / 작성일 | 한검증 / 2026-06-14 |

## 1. 검증 개요·범위
MY27 RKE 시스템에 대해 차량 수준 사이버보안 검증을 실차+보안 평가 랩 환경에서 2주간 수행. 검증 대상은 목표 CG-01/02, 클레임 CC-01, 운용환경 가정(진단포트 접근). 활동은 실차 재전송 시연·SE 키추출 시도·생산보안 감사 검토·OBD 접근성 점검.

## 2. 검증 결과 종합 ([RQ-11-01])
| 항목 | 결과 | 증적 참조 |
|---|---|---|
| 목표 적정성(CG-01,02) | 적정 | 수행기록 §1 |
| 목표 달성(CG-01,02) | 달성 | 재전송 200회 거부 로그, 키추출 실패 보고 |
| 클레임 유효성(CC-01) | 유효 | 공급사 감사 기록 |
| 운용환경 요구(진단포트) | 무효 | 일반 사용자 OBD 접근 확인 |

## 3. 부적합·잔여 리스크
| 부적합 항목 | 처리 방향 | 종결 상태 |
|---|---|---|
| 진단포트 접근 가정 무효 | 컨셉회귀(PRO-VCSMS-02-04) 진단위협 재평가 | 미종결(W14 기한, 책임 박위협) |

## 4. 종합 판정·케이스 권고
| 항목 | 내용 |
|---|---|
| 종합 판정 | 조건부유효 |
| 케이스 입력 권고 | 조건부수용(진단포트 부적합 종결 조건) |
| 케이스 전달 기록 | PRO-VCSMS-02-02 김보안 인수, 2026-06-14, 추적키 CG-01/02,CC-01,ENV-01 |

## 5. 결재
| 역할 | 성명 | 결정 | 일자 |
|---|---|---|---|
| 작성(검증 엔지니어) | 한검증 | 작성완료 | 2026-06-14 |
| 검토(Project CS Lead) | 김보안 | 이상없음 | 2026-06-14 |
| 승인(CSM) | 정관리 | 승인 | 2026-06-14 |

## 작성 시 유의사항
- 미종결 부적합은 종결 계획·책임·기한을 명시하고 케이스 릴리스 조건화(WI §7.1)
- 결과는 증적 참조로 뒷받침(증적 불충분 시 권고 수위 하향)
- 케이스 전달 시 목표·클레임 ID 추적키 명시(WI §7.3)

## 잘못된 작성 사례
> ❌ 진단포트 부적합 미종결인데 "유효" 판정 + 무조건 수용 권고
> ✅ "조건부유효 + 조건부수용(종결 조건)" 으로 정직 보고
> ❌ 케이스 전달 기록 없이 "전달함"
> ✅ 수신자·일자·추적키 명시로 단절 방지
