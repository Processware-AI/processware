# 보안 변경통제 요청 및 이력대장 작성예시 (EX-MDCS-01-04-01-01)

> ⚠️ 이 파일은 **교육·가이드용 가상 샘플** 입니다.

## 작성 안내
- 작성자 / 작성일 / 결재 경로: 가상인물 H(형상관리) / 2026-05-31 / 작성→CCB 심의·승인

## 1. 변경통제 요청
| 요청 ID | 변경 대상 형상 | 변경 내용 | 요청자 | 요청일 |
|---|---|---|---|---|
| CR-2026-077 | OpenSSL 1.1.1k→1.1.1w | CVE 패치 위한 버전 업 | 가상인물 C | 2026-05-28 |
| CR-2026-078 | 인증 토큰 만료시간 | 24h→1h 단축 | 가상인물 A | 2026-05-29 |

## 2. 보안 영향 심의
| 요청 ID | 위협 모델 영향 | 통제 영향 | 인터페이스 영향 | 심의 결론 |
|---|---|---|---|---|
| CR-2026-077 | 취약점 제거(긍정) | 암호 통신 통제 강화 | TLS 핸드셰이크 | 보안 강화, 회귀 필요 |
| CR-2026-078 | 탈취 노출 시간 감소 | 인증 통제 강화 | 세션 관리 | 승인, 사용성 영향 경미 |

## 3. CCB 결정 및 변경 이력
| 요청 ID | 결정(승인/반려) | 주체 | 일시 | 변경 내용 | 사유 | 연계(리스크/재시험) |
|---|---|---|---|---|---|---|
| CR-2026-077 | 승인 | 가상인물 C | 2026-05-30 10:00 | OpenSSL 1.1.1w 적용 | CVE 패치 | SBOM 갱신 + 회귀 검증 WI-03-03 |
| CR-2026-078 | 승인 | 가상인물 A | 2026-05-30 11:00 | 토큰 1h 적용 | 탈취 위험 감소 | 시스템 시험 일부 재실행 |

## 작성 시 유의사항
- 모든 변경은 요청 ID 로 등록하고 보안 영향 심의를 거친다(무단 변경 금지).
- 외부 컴포넌트 변경(CR-077)은 SBOM 갱신·재검증 연계를 명시한다.
- 변경 이력은 주체·일시·내용·사유를 모두 기록해 재현성을 확보한다.

## 잘못된 작성 사례
> ❌ 보안 영향 심의 없이 바로 반영 → 8-REQ-001 위반
> ✅ 위협/통제/인터페이스 영향 심의 후 CCB 승인
> ❌ 변경 이력에 "버전 올림" 만 — 주체·일시·사유 누락으로 재현 불가
