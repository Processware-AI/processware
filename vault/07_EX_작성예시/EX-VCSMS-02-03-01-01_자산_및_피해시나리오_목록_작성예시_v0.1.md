# 자산 및 피해시나리오 목록 작성예시 (EX-VCSMS-02-03-01-01)

> 원본 양식: [[TMP-VCSMS-02-03-01-01_자산_및_피해시나리오_목록]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 대상 (예시)
| 항목 | 예시값 |
|---|---|
| item/component | 중앙 게이트웨이 item "GW-X2" |
| 아이템 정의 참조 | WP-09-01 GW-X2 ItemDef v1.0 |
| TARA 차수 / 작성일 | 1차 / 2026-06-22 |

## 2. 자산 목록 (예시)
| 자산 ID | 자산명 | 설명 | 사이버보안 속성 |
|---|---|---|---|
| A-01 | OTA 펌웨어 이미지 | 게이트웨이 갱신 펌웨어 | 무결성, 진위성 |
| A-02 | 차내망 라우팅 메시지 | CAN-FD/Ethernet 제어 메시지 | 무결성, 가용성 |
| A-03 | 진단 세션 키 | UDS 보안 접근 키 | 기밀성, 무결성 |

## 3. 피해 시나리오 목록 (예시)
| 피해 시나리오 ID | 관련 자산 ID | 손상 속성 | 피해 내용 | 안전 중첩 |
|---|---|---|---|---|
| DS-01 | A-01 | 무결성 | 위조 펌웨어 설치로 차량 오작동·제어 탈취 | Y |
| DS-02 | A-02 | 무결성 | 제동 라우팅 메시지 변조로 제동 지연 | Y |
| DS-03 | A-03 | 기밀성 | 세션 키 유출로 무단 진단·재프로그래밍 | N |

## 작성 시 유의사항
- 자산은 "사이버보안 속성"이 있는 것만 등록한다(단순 부품 제외).
- 피해 시나리오는 "손상 속성 → 피해 내용"의 인과로 적는다.
- 안전 중첩(Y) 항목은 영향 평가에서 ISO 26262-3 §6.4.3 으로 안전 영향등급을 도출한다.

## 잘못된 작성 사례
> ❌ "자산: 게이트웨이" — 너무 포괄적, 속성 불명
> ✅ "자산: OTA 펌웨어 이미지 / 속성: 무결성·진위성"
> ❌ 피해 시나리오에 손상 속성 누락 — 위협 시나리오 연결 단절
