# 공급자 사이버보안 역량 평가표 작성예시 (EX-VCSMS-02-08-01-01)

> 원본 양식: [[TMP-VCSMS-02-08-01-01_공급자_사이버보안_역량_평가표]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 문서 정보 (예시)
| 항목 | 예시값 | 작성 요령 |
|---|---|---|
| 후보 공급자 | (주)에이콤시큐어 | 법인명 |
| 공급 대상 활동/품목 | TCU 보안 펌웨어 SW 개발 위탁 | 활동 + 품목 |
| 사이버보안 위험 수준 | 높음 | 보안 핵심 SW → 높음 |
| 평가자 / 평가일 | 박리드 (Project CS Lead) / 2026-06-20 | |
| 승인자(CSM) / 승인일 | 이보안 / 2026-06-22 | |

## 2. 제출 역량 기록 확인 (예시)
| 기록 종류 | 내용 | 최신성 | 검증 결과 |
|---|---|---|---|
| CSMS 인증 | UNECE R155 CSMS 적합 인증서 | 2025-11 발급, 유효 | 발급기관 대조 확인 |
| 프로세스 증빙 | 21434 준거 개발 프로세스 매뉴얼 | 2026-03 개정 | 샘플 산출물 확인 |
| 실적 | 타 OEM TCU 양산 2건 | — | 레퍼런스 확인 |

## 3. 영역별 평가 (예시)
| 평가 영역 | 가중치 | 점수(0~5) | 근거 |
|---|---|---|---|
| 프로세스(21434 준거) | 0.30 | 4 | 프로세스 매뉴얼·산출물 양호, 일부 TARA 깊이 부족 |
| 인력(역할·역량) | 0.20 | 4 | CS 전담 5인, 자격 보유 |
| 도구·환경 | 0.15 | 4 | 정적분석·퍼징 도구 운용 |
| 실적 | 0.15 | 5 | 유사 TCU 양산 2건 |
| 취약점 관리 역량 | 0.20 | 3 | 통지 프로세스 있으나 SLA 미정 |
| **가중 합산 점수** | 1.00 | **3.95 / 5** | — |

## 4. 종합 판정 (예시)
| 항목 | 내용 |
|---|---|
| 합격선 / 조건부선 | 4.0 / 3.0 |
| 판정 | 조건부 |
| 보완 요구 항목·기한 | 취약점 통지 SLA 정의·제출, 2026-07-15까지 |

## 5. 검토·승인 (예시)
| 역할 | 성명 | 의견 | 결과 | 일자 |
|---|---|---|---|---|
| 검토(조달) | 정조달 | 보완 기한 계약 조건에 반영 요청 | 승인의견 | 2026-06-21 |
| 승인(CSM) | 이보안 | 조건부 승인, 보완은 CIA 책임으로 명시 | 승인 | 2026-06-22 |

## 작성 시 유의사항
- 위험 수준이 "높음"이면 권고(역량 기록 제출)도 사실상 필수로 강하게 요구한다.
- 점수에는 반드시 근거를 기재한다(점수만 단독 기재 금지).
- 조건부 판정의 보완 요구는 기한과 함께 적고, CIA(WI-08-03)로 추적되게 한다.

## 잘못된 작성 사례
> ❌ 판정: "괜찮음" — 합격선 대비 근거 없음
> ✅ 판정: "조건부(3.95/4.0), 취약점 통지 SLA 보완 조건" — 점수·조건 명시
