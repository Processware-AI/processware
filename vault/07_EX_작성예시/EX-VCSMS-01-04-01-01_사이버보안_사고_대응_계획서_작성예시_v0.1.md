# 사이버보안 사고 대응 계획서 작성예시 (EX-VCSMS-01-04-01-01)

> 원본 양식: [[TMP-VCSMS-01-04-01-01_사이버보안_사고_대응_계획서]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 사고 개요 (예시)
| 항목 | 내용 |
|---|---|
| 사고 ID | INC-2026-0808-01 |
| 인지 시각 | 2026-08-08 11:20 |
| 영향 자산·차량 범위 | 텔레매틱스 ECU 통신 모듈, 2024~2025 MY 약 12,000대 |
| 잠정 원인 | VUL-2026-04(통신 라이브러리 취약점) 악용 시도 정황 |
| 사고 등급 | 중대 |

## 2. 대응 계획 7요소 (예시)
| 요소 | 내용 |
|---|---|
| (a) 조치 | 억제: 의심 트래픽 차단 룰 배포 / 근절: OTA 패치 / 복구: 정상 통신 검증 |
| (b) 소통·통보 | 규제기관 법정 기한 내 통보, 영향 고객 안내, 내부 경영진 즉시 보고 |
| (c) 책임 | 지휘=사고대응 팀장, 기술 조치=개발 리드, 소통=홍보, 법무=통보 검토 |
| (d) 기록 | 차량 SIEM 로그·트래픽 캡처 보존, 조치 타임라인 기록 |
| (e) 진척 추적 | 마일스톤: 차단(D0)→패치 빌드(D3)→배포 50%(D10)→배포 95%(D21) |
| (f) 종료기준 | 패치 배포 95% 이상 + 악용 정황 14일간 미재현 + 복구 검증 통과 |
| (g) 종료조치 | 차단 룰 정상화, 사후 리뷰, 재발방지 개선 등록 |

## 3. 소통·통보 계획 (예시)
| 대상 | 시점 | 채널 | 법적 기한 |
|---|---|---|---|
| 규제기관 | 인지 후 법정 기한 내 | 공식 통보 양식 | R155·국내 규제 준수 |
| 영향 고객 | 패치 배포 시작 시 | 고객 안내문·앱 알림 | — |
| 경영진 | 인지 즉시 | 긴급 보고 | — |

|---|---|---|
| 사고대응 팀장 | 최대응 | (내부 비상연락망) |

|---|---|---|---|---|

## 6. 작성 시 유의사항
- 7요소(조치·소통·책임·기록·진척·종료기준·종료조치)를 빠짐없이 채운다(누락은 §13.3 위반).
- 종료기준은 "안정화됨" 같은 모호 표현 대신 측정 가능한 조건으로 정의한다.
- 규제·고객 통보 의무는 정보공유 규칙·법규와 정합시키고 기한을 명시한다.

## 7. 잘못된 작성 사례
> ❌ 종료기준 "문제 해결되면 종료" — 검증 불가
> ✅ "패치 배포 95% + 악용 14일 미재현 + 복구 검증 통과" — 측정 가능
> ❌ 통보 대상·기한 미기재 — 법정 통보 의무 누락 위험
> ✅ "규제기관 법정 기한 내 통보" — 대상·기한 명시
