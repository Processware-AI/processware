# 제품 보안 맥락 문서 작성예시 (EX-MDCS-02-01-01-01)

> 원본 양식: [[TMP-MDCS-02-01-01-01_제품_보안맥락_문서_v0.1]]

> ⚠️ 이 파일은 **교육·가이드용 가상 샘플** 입니다.

## 작성 안내
- 작성자 / 작성일 / 결재 경로: 가상인물 A(위협모델링 리드) / 2026-05-08 / 작성→PSO 검토→PSO 승인

## 1. 제품 개요
| 항목 | 내용 |
|---|---|
| 제품/버전 | CareSync v4.0 |
| 의도된 사용 | 가정 내 환자 혈당 원격 모니터링 |
| 배포 형태 | 환자 단말 앱 + 제조자 클라우드(하이브리드) |

## 2. 의도된 환경·최소 보안 요건
| 환경 요소(네트워크/단말/연동) | 의도된 상태 | 최소 보안 요건 |
|---|---|---|
| 단말 | 사용자 스마트폰 | OS 최신 보안 패치, 화면 잠금 |
| 네트워크 | 공용 인터넷 경유 | TLS 1.2+ 통신 |
| 클라우드 연동 | 제조자 관리 클라우드 | 접근 통제·감사 로깅 |

## 3. 보안 가정·책임 경계
| 보안 가정 | 검증 가능 여부 | 책임 경계(제조자/사용자) |
|---|---|---|
| 단말 OS 가 보안 패치된 상태 | 부분(앱이 최소 버전 강제) | 사용자(동반문서 안내) |
| 클라우드 인프라 보안 통제 적용 | 예(제조자 운영) | 제조자 |
| 사용자가 강한 비밀번호 설정 | 부분(정책 강제) | 사용자 |

## 작성 시 유의사항
- 환경이 보장하지 않는 것을 무리하게 가정하지 않는다(검증 가능 여부 표기).
- 사용자 책임 가정은 반드시 동반문서로 전달 가능해야 한다.
- REQUIRED SW(단말 OS) 가정은 잔여 리스크와 연결한다.

## 잘못된 작성 사례
> ❌ "사용자 단말은 항상 안전하다" 가정 → 검증 불가, 위험
> ✅ "단말 OS 최신 패치 가정 + 앱이 최소 버전 강제 + 동반문서 안내"
> ❌ 책임 경계 미표기 → 사용자/제조자 책임 모호
