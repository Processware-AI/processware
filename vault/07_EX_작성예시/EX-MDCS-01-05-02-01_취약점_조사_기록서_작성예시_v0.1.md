## 작성 안내
- 작성자 / 작성일 / 결재 경로: 가상인물 I(triage) / 2026-06-01 / 작성→PSO 검토

## 1. 조사 대상
| 항목 | 내용 |
|---|---|
| 접수 ID | VUL-2026-060 |
| 보고 요지 | API 권한 우회 가능성(연구자 보고) |
| 대상 제품/버전 | CareSync API v3.2 |

## 2. 조사 판정
| 항목 | 판정 | 근거 |
|---|---|---|
| 제품 적용성(존재/비존재) | 적용(존재) | 특정 엔드포인트 권한 검사 누락 확인 |
| 검증 가능성(재현 가능/불가) | 재현 가능 | 보고 PoC 로 권한 상승 재현 |
| 관련 위협 | 수직 권한 상승, 환자 데이터 무단 열람 | 위협모델 T-권한상승 연결 |

## 3. 후속 조치
| 결정(분석 연계/종결) | 사유 | 연계 ID |
|---|---|---|
| 분석 연계 | 적용·재현 확인 | WI-MDCS-01-05-03 분석 착수 |

## 작성 시 유의사항
- 적용성·검증가능성·위협 3요소를 모두 판정하고 근거를 남긴다.
- 재현 가능하면 PoC 근거를 명시한다.
- 재현이 어려워도 적용 가능성이 있으면 보수적으로 분석 연계한다(§7.1).

## 잘못된 작성 사례
> ❌ 재현 미시도인데 "비적용 종결" → 보수적 분석 연계 원칙 위반
> ✅ 재현 시도 후 판정, 불확실 시 분석 연계
> ❌ 관련 위협 칸 공란 → 영향 분석 근거 부족
