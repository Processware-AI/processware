# 평가수행 결정서 작성예시 (EX-VCSMS-02-02-02-01)

> 원본 양식: [[TMP-VCSMS-02-02-02-01_평가수행_결정서]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 대상 (예시)
| 항목 | 예시값 |
|---|---|
| item/component | 중앙 게이트웨이 item "GW-X2" |
| 케이스 ID / 버전 | CASE-GWX2 / v1.0 |

## 2. 리스크 기반 결정 (예시)
| 항목 | 예시값 |
|---|---|
| 최고 리스크값(1-5) | 4 |
| 안전 연계 여부 | 예(제동 메시지 라우팅 영향) |
| 결정 기준 | 리스크값 ≥ 3 또는 안전 연계 시 평가 수행 필수 |
| 평가 수행 권고 | 수행(필수 — 안전 연계) |

## 3. 최종 결정·책임자 (예시)
| 항목 | 예시값 |
|---|---|
| 최종 결정 | 수행 |
| Assessor | 정독립 (품질본부, 개발라인과 분리) |

## 4. 독립 검토 (예시)
| 항목 | 예시값 |
|---|---|
| 독립 검토 의견 | 동의 |
| 검토 의견 상세 | 리스크값·안전 연계 근거 타당, 평가 범위에 OTA 경로 포함 권고 |
| 조정 내용 | OTA 경로를 평가 범위에 명시 추가 |

## 5. 승인 (예시)
| 항목 | 예시값 |
|---|---|
| 승인자(CSM) / 승인일 | 홍사보(CSM) / 2026-10-28 |

## 작성 시 유의사항
- 결정 기준(리스크값 임계·안전 연계)을 미리 명시해 자의적 판단을 배제한다.
- 안전 연계 item 은 미수행을 기본 차단하고 기능안전팀 동의를 요구한다.
- Assessor 는 개발라인과 분리된 인력을 지정한다(독립성).

## 잘못된 작성 사례
> ❌ "평가 미수행 — 바빠서" — 리스크 근거 없음, 안전 연계 무시
> ✅ "수행(필수) — 리스크값 4, 안전 연계(제동 라우팅)"
> ❌ Assessor 를 케이스 작성자와 동일 인물로 지정 — 독립성 위반
