# 업데이트 검증 및 배포 기록부 작성예시 (EX-VCSMS-02-09-02-01)

> 원본 양식: [[TMP-VCSMS-02-09-02-01_업데이트_검증_및_배포_기록부]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 업데이트 정보 (예시)
| 항목 | 예시값 |
|---|---|
| 업데이트 ID / 버전 | UPD-2026-TCU-031 / fw v3.2.1 |
| 연계 개발 명세서 | TMP-VCSMS-02-09-01-01 기록 #2026-009 |
| 검증자 / 검증일 | 조필드 (운영/필드) / 2026-09-16 |
| 배포 승인자(CSM) / 승인일 | 이보안 / 2026-09-18 |

## 2. 검증 항목·결과 (예시)
| 검증 항목 | 요구 ID | 검증 방법 | 결과(Pass/Fail) | 미충족 내용 |
|---|---|---|---|---|
| TLS 패치 적용 확인 | UPR-031-01 | HIL 침투 시험 재현 불가 확인 | Pass | — |
| 서명 검증 경로 무결성 | UPR-031-02 | 변조 펌웨어 거부 시험 | Pass | — |
| 롤백 동작 | 역량 요건 | A/B 롤백 강제 테스트 | Pass | — |

| 회귀 검증 결과 | 기존 보안 요구 23건 전수 재시험, 회귀 0건 |
|---|---|

## 3. 배포 게이트 (예시)
| 항목 | 내용 |
|---|---|
| 검증 판정(통과/반려) | 통과 |
| CSM 배포 승인 결과 | 승인(긴급도 높음, 점진 롤아웃 조건) |
| 배포 중단·롤백 임계값 | 실패율 2% 초과 시 중단 |

## 4. 배포 결과 (예시)
| 대상 VIN 수 | 성공 | 실패 | 롤백 | 커버리지% | 비고 |
|---|---|---|---|---|---|
| 120,000 | 116,400 | 480 | 480 | 97.0% | 실패율 0.4%, 임계값 이내 |

| 잔존 위험(미적용 차량) | 미적용 3,120대 — 재배포 큐 등록, 90일 내 재시도 계획 |
|---|---|

## 5. 검토·승인 (예시)
| 역할 | 성명 | 의견 | 결과 | 일자 |
|---|---|---|---|---|
| 검토(개발팀) | 한개발 | 실패 480건 원인=통신 타임아웃, 재배포로 해소 가능 | 승인의견 | 2026-09-17 |
| 승인(CSM) | 이보안 | 잔존 위험 추적 조건 승인 | 승인 | 2026-09-18 |

## 작성 시 유의사항
- 검증 Fail 항목이 하나라도 있으면 배포 게이트를 통과시키지 않는다(개발 반려).
- 배포 결과는 성공/실패/롤백/커버리지를 모두 수치로 기록한다.
- 미적용 차량은 "추후 처리"로 끝내지 말고 잔존 위험·재배포 계획을 남긴다.

## 잘못된 작성 사례
> ❌ 배포 결과: "정상 배포 완료" — 실패·롤백·커버리지 수치 누락
> ✅ 배포 결과: "116,400/120,000 성공(97.0%), 실패 480건 롤백" — 정량 기록
