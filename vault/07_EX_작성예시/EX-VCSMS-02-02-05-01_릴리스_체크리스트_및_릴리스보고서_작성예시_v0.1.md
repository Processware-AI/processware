# 릴리스 체크리스트 및 릴리스보고서 작성예시 (EX-VCSMS-02-02-05-01)

> 원본 양식: [[TMP-VCSMS-02-02-05-01_릴리스_체크리스트_및_릴리스보고서]]

> ⚠️ 이 파일은 **교육·가이드용 샘플** 입니다. 실제 기록으로 사용하지 마세요. 실제 기록은 `08_REC_기록/` 에 REC 로 생성.

## 1. 릴리스 대상 (예시)
| 항목 | 예시값 |
|---|---|
| item/component | 중앙 게이트웨이 item "GW-X2" |
| 릴리스 버전 | GW-X2 SOP R1.0 |
| 케이스 ID / 평가보고서 ID | CASE-GWX2 v1.1 / AR-GWX2 v1.0 |

## 2. 릴리스 산출물 가용화 (예시)
| 산출물 | 가용 여부 | 위치/ID |
|---|---|---|
| 사이버보안 케이스 | Y | CM-GWX2-CASE v1.1 |
| 평가 보고서 | Y | CM-GWX2-AR v1.0 |
| post-dev 사이버보안 요구 | Y | WP-10-02 v1.0 |

## 3. 릴리스 조건 게이트 (예시)
| 조건 | 충족 여부 | 증적 |
|---|---|---|
| 케이스 논거 충족(open 0) | Y | 생산검증 완료로 open 2건 종결 |
| 평가 확인(수용/조건 종결) | Y | AR 조건 2건 11/28 종결 |
| post-dev 요구 수용 | Y | 생산·운영팀 인수 확인 |
| 게이트 결과 | 통과 | — |

## 4. 릴리스 결정·기록 (예시)
| 항목 | 예시값 |
|---|---|
| 릴리스 결정 | 승인 |
| 승인자(경영진) / 결정일 | CTO 홍길동 / 2026-12-01 |
| 형상 등록 ID | CM-GWX2-REL-001 |

## 작성 시 유의사항
- 게이트 3개 조건이 모두 Y 여야만 게이트 결과가 "통과"가 된다(하나라도 N이면 차단).
- open 논거·조건부 조건 종결은 증적(검증 보고)으로 확인한다.
- 릴리스 결정·근거를 형상관리에 등록해 추적성을 보존한다.

## 잘못된 작성 사례
> ❌ open 논거 1건 남았는데 게이트 "통과" 표기 — 게이트 우회(금지)
> ✅ open 0 확인 후 통과, 종결 증적 명시
> ❌ "릴리스 승인 / 근거: 일정 압박" — 조건 충족이 근거여야 함
