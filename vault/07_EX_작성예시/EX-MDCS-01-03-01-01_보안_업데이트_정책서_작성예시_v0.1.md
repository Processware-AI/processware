# 보안 업데이트 정책서 작성예시 (EX-MDCS-01-03-01-01)

> 원본 양식: [[TMP-MDCS-01-03-01-01_보안_업데이트_정책서_v0.1]]

> ⚠️ 이 파일은 **교육·가이드용 가상 샘플** 입니다.

## 작성 안내
- 작성자 / 작성일 / 결재 경로: 박거버(PSO) / 2026-05-04 / 작성→PSGB 검토→PSO 승인

## 1. 적용 범위
| 항목 | 내용 |
|---|---|
| 대상 제품/제품군 | CareSync 제품군 |
| 적용 SW 분류 | MAINTAINED(앱·API), SUPPORTED(관리형 DB) |

## 2. 영향평가 기준
| 평가 요소 | 등급 기준(상/중/하) |
|---|---|
| 영향(심각도) | 상: CVSS≥9.0 / 중: 7.0~8.9 / 하: <7.0 |
| 인지도(공개성) | 상: 공개 PoC 존재 / 중: 벤더 공지 / 하: 내부 발견 |
| 익스플로잇 가능성 | 상: 원격 무인증 / 중: 인증 필요 / 하: 로컬 |
| 배포량 | 상: 전 사용자 / 중: 일부 / 하: 소수 |
| 외부 통제 가용성 | 상: 없음 / 중: 부분 완화 / 하: 네트워크 통제로 차단 가능 |

## 3. 영향 등급별 SLA·대응
| 영향 등급 | 검증 SLA | 전달 SLA | MAINTAINED 대응 | SUPPORTED 대응 |
|---|---|---|---|---|
| 긴급(상) | 3일 | 7일 | 핫픽스 배포 | 즉시 안내+완화책 |
| 높음(중) | 7일 | 30일 | 정규 패치 | 다음 안내 |
| 보통(하) | 30일 | 다음 정규 릴리스 | 정규 릴리스 포함 | 릴리스 노트 안내 |

## 작성 시 유의사항
- 영향평가 5요소를 모두 등급화한다(누락 시 일관된 우선순위 판정 불가).
- 규제 대응 기한이 SLA 보다 짧으면 규제 기한을 우선한다.
- SUPPORTED 는 직접 패치가 아닌 안내·완화책 제공으로 명시한다.

## 잘못된 작성 사례
> ❌ SLA 를 "최대한 빨리" 로 기재 — 측정·준수율 산정 불가
> ✅ "긴급: 검증 3일/전달 7일" 처럼 정량화
> ❌ SUPPORTED 에 "패치 제공" 기재 — 제조자 직접 패치 불가 분류와 모순
