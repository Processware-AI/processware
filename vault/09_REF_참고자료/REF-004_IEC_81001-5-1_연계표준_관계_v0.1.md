# IEC 81001-5-1 연계 표준 관계 (REF-004)

> 최종 확인일: 2026-06-18
> 본 REF 는 `interface_only` 표준인 IEC 81001-5-1 이 인접 의료기기 표준과 맺는 경계면을 정리. 표준 본문이 직접 인용하는 hard interface 와 레지스트리가 선언한 soft interface 를 구분.

## 요약
IEC 81001-5-1 은 단독으로 완결되지 않고, 의료기기 QMS(ISO 13485)·SW 수명주기(IEC 62304)·리스크 관리(ISO 14971) 와 함께 운용되도록 설계되었다. 보안 활동은 이들 표준의 프로세스에 "보안 관점"을 주입하는 형태로 통합된다.

## 경계면 매핑
| 인접 표준 | 영역코드 | 경계면 | IEC 81001-5-1 측 | 인터페이스 종류 |
|---|---|---|---|---|
| **ISO 13485:2016** | MDQMS | QMS·문서·교육·정기검토 | §4.1.1, §4.1.2, §4.1.4, **§4.1.8-REQ-003 (명시 인용)** | **hard** (본문 직접 참조) |
| **IEC 62304** | MDSW | SW 개발·유지보수·구성관리·문제해결 | Clause 5·6·8·9 전반 | structural (구조 병행) |
| **ISO 14971** | MDRM | 제품/안전 리스크 ↔ 보안 리스크 | §4.2, Clause 7, §9.5-REQ-003 | structural (RM 파일 통합) |
| **ISO/IEC 29147** | — | 취약점 공개 | **§9.2-REQ-002(f) (명시 인용)** | **hard** (본문 직접 참조) |

## 적용 영향
- **현재 MDQMS/MDSW/MDRM 미빌드** → 본 적용요건의 경계면 7건(§9)은 "향후 연계" 상태.
- 향후 해당 표준 편입 시: process-designer 가 MDCS 전용 PRO 에서 인접 PRO 로 참조 wikilink 추가(통합 금지, interface_only 규약).
- hard interface(ISO 13485 §4.1.3, ISO/IEC 29147)는 우선 매핑 대상.
