# IEC 62443-4-1 과 IEC 81001-5-1 관계 (REF-003)

> 원문 출처: IEC 62443-4-1:2018 (산업 자동화·제어 시스템 보안 개발 수명주기)
> 최종 확인일: 2026-06-18
> 근거: IEC 81001-5-1 `definitions.yaml` 의 다수 용어(ATTACK SURFACE 등)가 IEC 62443-4-1:2018 을 출처로 명시 → 두 표준의 구조적 계보를 확인. IEC 62443 원문 자체는 미투입(`[inputs 미제공 — LLM 추정]` 구조 부분).

## 요약
IEC 81001-5-1 은 IEC 62443-4-1 의 **보안 개발 수명주기(SDL) 구조를 헬스SW 도메인으로 적응**한 표준이다. 용어 정의·활동 구조(요구사항→설계→구현→검증→릴리스→유지보수→문제해결)가 직접 대응된다. 따라서 이미 62443-4-1 을 운영하는 조직은 81001-5-1 갭이 작다.

## 적용 영향
- 62443-4-1 인증 보유 조직: 81001-5-1 편입 시 기존 SDL 기록 재활용 가능. 단 헬스SW 고유(안전·임상·동반문서·전환SW Annex F) 보강 필요.
- 용어 일관성 확보: 본 적용요건의 대문자 용어는 62443 계보를 따름.
