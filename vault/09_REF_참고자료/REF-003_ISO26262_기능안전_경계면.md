# REF-003 ISO 26262 — 기능안전 경계면

> 관련 모듈: [[적용요건|ACSMS 적용요건]] · 영역코드 FUSA(별도 빌드 대상) · 표준: ISO/SAE 21434 §15.5 (interface_with)

## 1. 개요
ISO 26262 는 도로차량 E/E 시스템의 **기능안전(functional safety)** 표준(12 Part, V-model)이다. ISO/SAE 21434(사이버보안)는 안전(safety)과 보안(security)의 상호작용 지점에서 ISO 26262 를 명시적으로 참조한다.

## 2. ISO/SAE 21434 와의 직접 인용 지점
- **§15.5 [RQ-15-06] (VCSMS-R-107)**: TARA 의 안전 관련 영향등급(impact rating)을 **ISO 26262-3:2018 §6.4.3** 의 심각도(severity) 분류에서 도출하도록 요구.
- 안전 목표(safety goal)와 사이버보안 목표(cybersecurity goal)의 일관성, 위협이 안전에 미치는 영향(S 범주) 분석에서 두 표준이 교차.
