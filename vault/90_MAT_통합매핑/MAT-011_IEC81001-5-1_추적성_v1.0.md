# MAT-011 IEC 81001-5-1 추적성 매트릭스

> 대상 표준: **IEC 81001-5-1:2021** — Health software — Part 5-1: Security — Activities in the product life cycle
> 영역코드: **MDCS** · Integration mode: **interface_only**
> 상위: [[MOC_추적성매트릭스]] · 적용요건: [[적용요건]] (REQ-iec81001-5-1) · 플로우: [[MAT-010_프로세스_플로우_맵]]
> 유사 매트릭스와의 역할 구분: MAT-002(법규 조항 축) · MAT-006(문서 계층 구조 축) · **MAT-011(본 문서 = Req-ID 축)**

## 목적

IEC 81001-5-1:2021 의 **95개 요구사항(REQ)** 각각이 어느 **POL → PRO → WI → TMP → EX** 로 흐르는지(forward), 그리고 각 산출물이 어느 REQ 를 충족하는지(backward) 행 단위로 매핑하여 요구사항 커버리지의 완결성을 입증한다. 각 REQ 행은 `source_citation`(조항·페이지)을 보존하여 심사 시 표준 원문 추적이 가능하다.

## 범위

- 대상: 적용요건 95개 REQ 전부 (Clause 4: 13 거버넌스 + 4.2 리스크 4 / Clause 5: 35 / Clause 6: 8 / Clause 7: 14 / Clause 8: 2 / Clause 9: 10 / Annex F: 8).
- 미커버 리프 2건(9.1·F.1 Overview = normative shall 없음)은 §3 에 분리 표기.
- WI↔TMP↔EX 는 1:1:1 (동일 6자리 prefix 공유). 표에서는 WI 컬럼 1개로 대표하고, TMP/EX 는 동일 prefix 로 자동 도출(§4 참조).

## 상태 기호 범례

| 기호 | 의미 |
|---|---|
| ✅ 반영완료 | POL + PRO + WI + TMP + EX + 증적 예상경로 전 계층 링크 존재 |
| 🟡 작업중 | 일부 계층 누락 (예: REC 미생성 — 운영 단계 보완) |
| ⛔ 미착수 | 매핑 없음 |
| — | 의도적 미커버 (요구사항 없음) |

> 본 표준 95개 REQ 는 전부 POL→PRO→WI→TMP→EX 5단 계층이 존재한다. REC(기록 인스턴스)는 차원 2(Do) 실행 시 생성되므로 현 시점 모든 행은 **🟡 작업중**(5단 문서 완비, REC 예상경로만 명시) 으로 표기한다.
