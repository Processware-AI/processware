# MAT-011 VCSMS (ISO/SAE 21434) 추적성 매트릭스

> 기준: [[표준프로세스_구성원칙]] · 문서체계: [[01_문서체계]] · 번호규칙: [[02_문서번호체계]] §MAT 번호 할당 원칙
> 상위 인덱스: [[MOC_추적성매트릭스]] · 적용요건: [[적용요건]] (REQ-VCSMS)
> 통합방식: **interface_only** — HLS POL/PRO 미병합. 경계면(공급자·변경/문서/형상·정보보안·역량·리스크거버넌스·내부심사)은 상위 L1 "참조" 링크로만 표기(§5 Interface).
> 본 매트릭스의 축 구분:
> - MAT-002(규제요구사항 대조표): **법규/규제 조항** 축
> - MAT-006(문서계층 추적): **문서 계층(구조)** 축
> - **MAT-011(본 문서)**: **Req-ID(VCSMS-R / native [RQ/RC/PM]) ↔ 전 계층** 축

## 목적
ISO/SAE 21434:2021 의 요건 118건(VCSMS-R-001~118 + native `[RQ/RC/PM-NN-MM]`)이 POL → PRO → WI → TMP/EX → 증적(REC 예상경로)으로 빠짐없이 도달함을 단일 표로 보증하고, 미커버 요건(req_uncovered)과 공백을 가시화한다.

## 범위
- 적용요건([[적용요건]] REQ-VCSMS) 의 전(全) 118 요건.
- design 산출 POL 2 / PRO 13, write 산출 WI 60 / TMP 60 / EX 60.
- 경계면 요건(QMS/ISMS 위임분)은 interface 참조로 명기(§5).
