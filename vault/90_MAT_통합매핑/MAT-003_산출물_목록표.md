### IEC 81001-5-1 (MDCS) 산출물 상세 (design 단계)
- **POL (2)**: POL-MDCS-01 보안 거버넌스 방침, POL-MDCS-02 보안 리스크 관리 방침
- **PRO (7)**: PRO-MDCS-01-01 거버넌스·일반요건, 01-02 보안 SW 개발, 01-03 유지보수, 01-04 형상관리, 01-05 문제해결, 01-06 과도기 헬스SW, 02-01 보안 리스크 관리
- **WI 생성 완료 (33)**: 01-01:5, 01-02:8, 01-03:4, 01-04:2, 01-05:6, 01-06:3, 02-01:5 (write 단계 전수 생성)
- **TMP/EX 생성 완료 (33/33)**: WI 와 1:1:1 (동일 6자리 prefix + -01)
- **REQ 커버리지**: 95개 전수 매핑 (POL→PRO→WI→TMP→EX 5단), 미커버 9.1·F.1 Overview 서론 2건 — 의도적 제외. 상세: [[MAT-011_IEC81001-5-1_추적성_v1.0]]
- **REC**: 미생성 (차원 2 `/process-do` 실행 시 생성)
